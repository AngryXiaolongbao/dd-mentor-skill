## 1. 使用边界和框架映射

本指南将并购准备资料概括为九类：公司记录、近期财务报表、审计及内控材料、近年纳税申报、财务制度和流程、重大合同、预算和预测、商业或战略计划，以及会计账簿或系统数据。该框架只是起点，实际范围会因交易和估值方法而变化，并购还可能采用资产收购结构。

本指南从买方、投资人和融资方的风险判断出发，进一步扩展交易结构、盈利质量、营运资金、净债务、融资条款、交割、整合和投后事项。

本指南采用相对中性的交易语言，不能替代具体司法辖区的法律、税务、会计、外汇、反垄断或行业监管意见。项目使用时必须按交易地点、主体类型和融资工具重新判断适用性。

| 基础准备框架 | 本指南对应章节 | 教学重点 |
| --- | --- | --- |
| 公司记录 | 第3章 | 权属、控制权、授权及稀释 |
| 财务报表 | 第4、5章 | 报表可靠性、盈利质量、现金和估值基础 |
| 审计及内控 | 第6章 | 外部保证程度、内控缺陷和管理层凌驾 |
| 纳税申报 | 第7章 | 税会勾稽、历史敞口及交易税务 |
| 财务制度和流程 | 第6章 | 关键流程是否持续、可复制和可整合 |
| 重大合同 | 第8章 | 权利义务、控制权变更和交割同意 |
| 预算和预测 | 第9章 | 估值假设、历史准确性及下行情景 |
| 商业和战略计划 | 第10章 | 投资逻辑、协同和持续经营 |

## 2. 交易画像与范围

### 要证明什么

交易目的、交易类型、拟取得权利、估值逻辑、资金安排和退出或整合路径相互一致。

### 为什么重要

并购、少数股权融资和债务融资对控制权、偿债、信息权和交割条件的关注不同。未先理解交易画像，DDQ容易变成无重点的资料堆积。

### DDQ

1. 本次交易的商业目的、发起背景和时间表是什么？
2. 拟采用股权收购、资产收购、增资、老股转让、可转债、贷款还是混合结构？
3. 投资人或买方拟取得多少经济权益、表决权、董事席位和保护性权利？
4. 估值基于收益法、市场法、资产法还是多种方法交叉验证？
5. 定价、交割调整、业绩承诺、回购、清算优先、反稀释或担保安排是什么？
6. 交易资金来源、资金用途和交割后最低现金需求是什么？
7. 是否涉及剥离、重组、关联资产注入、跨境审批或第三方同意？
8. 买方、投资人或融资方最重要的三项投资假设是什么？
9. 是否涉及反垄断、外商投资、国家安全审查、行业准入或其他交易审批？

### 证据和程序

- 将交易方案、意向书、投资协议草案、估值模型、董事会材料和资金计划勾稽；
- 绘制交易前后股权、表决权、债务、现金和担保变化图；
- 将每个核心投资假设映射到证据、责任工作流和否定该假设的触发条件；
- 明确资料基准日、财务期间、重要性口径和是否需要专家。

### 异常分支

- 交易目的与资金用途不一致 → 穿透真实资金需求及潜在关联安排；
- 估值方法与业务成熟度不匹配 → 增加替代估值及敏感性分析；
- 结构频繁变化 → 核查税务、控制权、审批或历史瑕疵是否驱动结构调整。

## 3. 公司记录、股权及治理

### 要证明什么

目标公司合法存续，股权和证券权利完整清晰，决策授权有效，交割后权利能够落实。

### DDQ

1. 请提供设立文件、章程及全部修订、股东和董事会会议文件、组织架构图。
2. 请提供最新资本结构表，并列示各类股份、期权、认股权、可转债及其他潜在稀释工具。
3. 请提供历次增资、转让、回购、代持解除、员工持股和股权激励文件及付款证据。
4. 是否存在质押、冻结、信托、代持、表决权委托、一致行动或优先购买权？
5. 哪些事项需要股东、董事、债权人、监管机构或合同相对方批准？
6. 是否存在未写入章程或正式协议的口头安排、补充协议或特殊股东权利？
7. 对融资项目，请说明本轮前后完全摊薄资本结构、创始团队持股和后续融资空间。

### 证据链

`设立及章程 → 股东决议 → 认购或转让协议 → 资金支付 → 股东名册和登记 → 当前权利及负担`

### 异常信号和后续

- 资本结构表与工商或协议不一致 → 重建 fully diluted cap table，并取得法律确认；
- 出资资金回流或价格异常 → 扩大流水、税务和关联关系核查；
- 历史特殊权利未解除 → 评价对控制权、交割和新投资人权利的影响。

## 4. 财务报表、账簿和数据

### 要证明什么

财务报表与账簿、业务系统和银行记录一致，能够支持估值、偿债和交割调整。

### DDQ

1. 请提供最近三年及最新一期的利润表、资产负债表、现金流量表和权益变动资料。
2. 请提供月度或最短常规关账周期的管理报表、KPI及管理层经营分析。
3. 请提供试算平衡表、总账、明细账、科目余额表和主要业务系统数据字典。
4. 财务报表是否经审计、审阅或编制？请提供报告、管理建议书及调整分录。
5. 报告口径、会计政策、合并范围和关键估计在各期间是否一致？
6. 是否存在表外安排、未入账账户、个人账户、特殊目的主体或管理层手工调整？
7. 账簿或系统数据能否按客户、产品、地区、渠道、合同及项目下钻？
8. 请说明数据导出方式、系统权限、日志保留及数据完整性验证方法。

### 证据和程序

- 报表勾稽至试算平衡表、明细账、银行、税务和业务系统；
- 分析月度趋势，识别期末冲量、大额手工分录和口径变化；
- 选择主要及异常科目，从报表向原始交易反查，并从业务记录正向测试完整性；
- 对融资项目重点检查现金余额、资金消耗和可用额度；对并购项目增加交割基准日数据准备。

### 异常分支

- 只能提供年度汇总 → 降低对趋势和截止结论的信赖，增加原始数据和替代程序；
- 管理报表与法定报表长期不一致 → 建立差异桥并评价估值口径；
- 系统数据可被无日志修改 → 引入IT专家并降低电子证据可信度。

## 5. 盈利质量、营运资金和净债务

### 要证明什么

可持续盈利、正常营运资金和净债务能够被可靠量化，定价不会被一次性项目或分类差异误导。

### DDQ

1. 请按产品、客户、地区和渠道分解收入、毛利及贡献利润。
2. 请列示非经常、非经营、关联、一次性和管理层主张的调整项目。
3. 请说明收入确认、返利、退货、质保、可变对价和截止政策。
4. 请提供应收、存货、应付及合同负债的账龄、周转和期后实现资料。
5. 请说明季节性、正常化营运资金水平及交易日前后可能的窗口修饰。
6. 请列示借款、租赁、票据、保理、担保、应计未付、或有付款和其他类债务项目。
7. 请列示受限资金、非经营性资产和可能作为类现金处理的项目。
8. 请说明客户或供应商集中、价格变动和关键合同续签对盈利的影响。
9. 请列示关联方交易、余额、费用分摊和交易后需要终止或继续的安排。

### 证据链

`历史报表 → 明细和业务驱动 → 正常化调整 → 可持续 EBITDA或现金流 → 营运资金/净债务 → 估值和交割价格`

### 主要程序

- 建立报告利润到正常化利润的调整桥；
- 检查每项调整是否有事实证据、是否重复、是否真正非持续；
- 计算月度营运资金并识别季节性和基准水平；
- 将净债务定义与交易协议逐项对齐，避免现金、租赁或或有项目重复计算；
- 对融资项目将现金消耗、融资金额和经营里程碑形成 runway 分析。

### 异常分支

- 大量“调整后利润”缺乏原始证据 → 采用未调整或分情景估值；
- 交割前异常催收、延迟付款或压低库存 → 调整正常营运资金目标；
- 债务和类债务定义不清 → 在交易文件中形成逐项定义和争议处理机制。

## 6. 审计、内控和财务流程

### 要证明什么

财务信息的外部保证程度和内部生成流程足以支持交易判断，重大缺陷已被识别和量化。

### DDQ

1. 请提供最近审计、审阅或其他鉴证报告，以及审计调整和未调整差异。
2. 请提供管理建议书、内控评价、内部审计、整改计划和持续运行证据。
3. 请说明工资、采购、付款、销售、应收、资金和银行对账流程。
4. 关键岗位是否实现授权、执行、记录、保管和复核分离？
5. 管理层能否绕过系统、付款、合同、印章或收入确认控制？
6. 过去三年是否发生财务重述、舞弊、举报或重大系统故障？
7. 交割或融资后是否需要升级财务系统、关账流程、预算和投资人报告？

### 程序和异常分支

- 对关键流程执行穿行测试并抽查控制执行；
- 将制度与实际操作、系统权限和底层证据比较；
- 发现管理层凌驾、职责不分或整改反复 → 扩大实质性测试，量化交易后整改成本，并将关键整改列为交割条件或投后事项。

## 7. 税务

### 要证明什么

历史税务申报与账面一致，重大税务敞口、优惠持续性和交易结构税负被识别。

### DDQ

1. 请提供最近三年主要税种申报、完税凭证、税务鉴证和对应财务报表。
2. 请说明税会差异、递延所得税、未弥补亏损和税收优惠。
3. 是否存在历史重组、股权转让、关联交易、跨境交易或常设机构风险？
4. 是否接受过税务检查、问询或处罚？是否存在未决争议？
5. 股权收购和资产收购的税务结果有何差异？
6. 融资工具的利息、股息、可转债、股份支付和代扣代缴情形如何处理？
7. 本轮资金用途是否影响优惠资格、资本弱化或利息扣除？

### 证据和程序

- 将申报收入、成本、工资和资产与账面及现金流勾稽；
- 量化税务敞口、滞纳金和处罚区间；
- 对结构选择进行税后现金流比较；
- 重大不确定事项交税务专家，并明确是否形成价格调整、赔偿、托管或交割条件。

## 8. 重大合同和交易同意

### 要证明什么

重大权利义务完整，交易不会触发违约、终止或不可接受的重新谈判。

### DDQ

1. 请提供股权、债务、租赁、员工、客户、供应商、专业服务、和解及其他重大合同。
2. 请列示控制权变更、转让限制、排他、最低承诺、最惠条款、回购、赔偿和终止条款。
3. 哪些合同需要因本次交易取得同意、豁免或重新签署？
4. 是否存在口头承诺、补充协议、折扣返利安排或实际履行偏离？
5. 重大客户或供应商是否有权因融资、控制权或管理层变化终止合作？
6. 债务协议是否限制新增融资、股息、资产处置、担保或控制权变化？
7. 是否存在诉讼和解、监管承诺或未披露或有义务？

### 证据链和异常分支

`合同台账 → 原件及修订 → 实际履行 → 账务和付款 → 控制权变更/融资限制 → 所需同意 → 交割条件`

- 合同台账与账务或印章记录不一致 → 扩大完整性检索；
- 关键合同可因交易无责终止 → 将同意纳入先决条件并开展客户或供应商留存计划；
- 实际履行偏离合同 → 评价收入、成本、争议和可执行性。

## 9. 预算、预测和估值

### 要证明什么

预测由可验证的业务驱动构成，历史准确性和下行情景足以支持估值和融资规模。

### DDQ

1. 请提供当前及以前年度预算、滚动预测、销售预测和现金流计划。
2. 请比较历史预算与实际结果并解释主要偏差。
3. 收入、价格、销量、毛利、人员、资本开支和营运资金假设是什么？
4. 预测是否包含尚未签约客户、未获批产品、未落实产能或未确定融资？
5. 管理层预测、董事会版本、估值模型和对外融资材料是否一致？
6. 收益法、市场法和资产法分别使用哪些数据和调整？
7. 请提供基准、下行和压力情景，以及流动性最低点。
8. 并购协同、一次性整合成本或融资后增长投入是否单独列示？

### 程序

- 以历史准确性评价管理层预测可信度；
- 将预测拆分为数量、价格、客户、产能、人员和现金驱动；
- 对关键变量执行敏感性和反向压力测试；
- 将企业价值到股权价值的桥与净债务、营运资金和潜在稀释勾稽；
- 不以估值模型本身替代对商业假设的验证。

### 异常分支

- 预测主要依赖未签约或未批准事项 → 降低基准情景、设置里程碑或分期出资；
- 历史预算持续高估 → 采用外部或下行情景并调整估值；
- 协同效应无责任人和时间表 → 不纳入基础估值，转为交易后上行。

## 10. 商业计划、战略及经营

### 要证明什么

商业计划与实际经营、竞争优势、资金需求和交易后战略一致。

### DDQ

1. 请提供商业计划、战略计划、管理层摘要和董事会战略材料。
2. 公司如何获得客户、交付产品或服务并实现现金回收？
3. 主要市场、竞争对手、替代品、政策和技术变化是什么？
4. 关键客户、供应商、渠道、许可证、技术和人员依赖是什么？
5. 交易或融资后最重要的经营里程碑、资本开支和招聘计划是什么？
6. 并购整合或融资扩张对产能、系统、组织和现金流有何影响？
7. 如果交易失败、融资延迟或业务下行情景发生，公司如何维持经营？

### 程序和异常分支

- 将商业计划与合同、订单、市场证据、财务结果和预测勾稽；
- 识别管理层材料之间的口径差异；
- 增长显著背离行业或资源能力 → 进行客户验证、产能验证和现金压力测试；
- 计划依赖单一人员或外部资源 → 形成留任、替代和交易保护安排。

## 11. 融资结构、条款和资金用途

### 要证明什么

融资工具、金额、估值、投资人权利和资金用途与公司的现金需求及风险承受能力匹配。

### DDQ

1. 本轮拟融资金额、估值、工具、交割批次和最低交割条件是什么？
2. 请提供本轮及历史 term sheet、投资协议、股东协议、可转债或借款文件。
3. 请列示清算优先、反稀释、回购、优先认购、共同出售、拖售、信息权、否决权和董事席位。
4. 请提供融资前后 fully diluted cap table 和不同退出估值下的分配瀑布。
5. 资金用途如何分配至运营、研发、资本开支、偿债、收购和股东退出？
6. 资金可支持多少个月运营？哪些里程碑决定下一轮融资？
7. 是否存在其他投资人的最惠、同意、优先权或触发条款？
8. 债务融资的利率、期限、摊还、财务约束、抵押、担保和违约事件是什么？
9. 若融资金额不足、交割延期或下一轮估值下降，公司如何调整计划？

### 证据和程序

- 建立融资前后资本结构、权利和经济分配模型；
- 将资金用途与月度现金流、合同承诺和经营里程碑勾稽；
- 对关键契约执行历史和预测合规测试；
- 评价投资人保护是否实质改变控制权或形成会计负债；
- 将未达到里程碑、down round 和偿债压力纳入情景分析。

### 异常分支

- 资金主要用于填补长期经营亏损但无转折计划 → 提升持续经营和分期出资风险；
- 回购义务由创始人或公司无条件承担 → 评价可执行性、控制权和负债影响；
- 债务期限短于现金回收周期 → 重构期限、增加备用额度或降低融资规模。

## 12. 人员、知识产权、IT及合规

### 要证明什么

交易价值所依赖的人员、技术、系统和许可可以持续并合法转移或使用。

### DDQ

1. 请提供关键人员、劳动合同、激励、竞业、保密和留任安排。
2. 请列示专利、商标、软件、域名、商业秘密及其创造、受让和许可链。
3. 是否存在职务发明、开源软件、合作研发或前雇主权利争议？
4. 请提供主要IT系统、数据流、权限、网络安全和个人信息合规资料。
5. 是否存在许可、处罚、诉讼、举报、商业贿赂、环保安全或数据事件？
6. 交易是否触发数据迁移、跨境传输、许可证变更或员工安置？
7. 请提供保险范围、理赔历史和交易后需延续的保单。

### 异常分支

- 核心技术由创始人个人或关联方持有 → 要求交割前确权或许可保护；
- 关键人员无留任安排 → 建立留任激励并调整协同实现假设；
- 系统和数据不能剥离或迁移 → 量化过渡服务和替换成本；
- 重大合规事项未量化 → 引入专家并设置赔偿、托管或先决条件。

## 13. 客户、供应链、资产及运营

### 要证明什么

收入和生产经营的关键依赖可持续，实物资产、库存和运营能力能够支持商业计划，交易不会因客户流失、供应中断或资产缺陷减值。

### DDQ

1. 请按收入、毛利和应收余额列示主要客户，并说明合同期限、续签、流失率、获客成本和销售管线。
2. 请列示订单、在手合同、积压订单、取消权、退货、返利和质保义务。
3. 请按采购额和关键物料列示主要供应商，并说明单一来源、替代周期、价格机制和最低采购承诺。
4. 请提供主要场地、土地房产、租赁、固定资产、在建工程和资本开支计划。
5. 请提供产能、产量、销量、利用率、维护停机、能源和关键设备资料。
6. 请提供存货分类、库龄、盘点、第三方仓储、在途、发出商品及跌价资料。
7. 请说明产品质量、召回、质保、责任索赔、认证和监管检查情况。
8. 请提供财产、责任、董责、网络、产品及关键人员等保险和历史理赔资料。
9. 交易或融资后是否存在扩产、搬迁、供应切换或客户重新认证需求？

### 证据和程序

- 将客户和供应商集中度与合同、订单、回款、采购、库存和预测勾稽；
- 对关键客户续签、流失及销售管线进行分层验证；
- 对单一来源和长周期物料测试替代性和安全库存；
- 现场观察重大资产、库存和产能，检查权属、状态、维护和减值；
- 将资本开支与产能、订单、资金用途和现金流预测对应；
- 检查质量事件、召回、赔偿和保险覆盖是否完整反映。

### 异常分支

- 关键客户无长期合同且交易后可自由终止 → 降低收入协同并设置客户留存条件；
- 单一来源物料无替代方案 → 增加库存、价格和停产压力测试；
- 产能数据与设备、人员或能源不匹配 → 现场核验并重估增长预测；
- 库龄恶化或盘点差异 → 重算跌价和正常营运资金；
- 重大质量或责任风险超过保险覆盖 → 设置专项赔偿、托管或价格调整。

## 14. 并购特有扩展

### 14.1 交易边界

1. 收购的是股份、资产、业务、子公司还是组合？
2. 哪些资产、负债、人员、合同和数据明确纳入或排除？
3. 剥离财务数据能否与历史法人报表可靠分拆？
4. 是否需要过渡服务协议、品牌许可、共享系统或关联供应？

### 14.2 价格和交割

1. 采用锁箱、交割账目还是固定价格？
2. 允许泄漏、净债务、现金和正常营运资金如何定义？
3. 交割日前经营承诺、重大不利变化及长停日期如何约定？
4. 赔偿、托管、保证保险和责任上限如何覆盖已识别风险？

### 14.3 协同和整合

1. 收入及成本协同分别由哪些客户、采购、人力和系统措施产生？
2. 一次性整合成本、实现周期、责任人和失败条件是什么？
3. 是否存在文化、客户流失、关键人员、系统迁移或监管整合风险？
4. Day 1、前100天和长期整合计划如何安排？

### 教学逻辑

`交易边界不清 → 历史数据不能代表被收购业务 → 估值和交割调整失真 → 需建立剥离口径、过渡安排和价格保护`

## 15. 融资特有扩展

### 15.1 股权融资

- 核查估值、稀释、投资人权利、创始团队控制和后续融资空间；
- 对关键里程碑、分期交割和资金用途设置可验证指标；
- 模拟 down round、退出和清算分配，识别权利不对称。

### 15.2 债务融资

- 核查偿债来源、抵押担保、契约余量、现金回收周期和再融资风险；
- 对利率、汇率、需求下滑和营运资金占用执行压力测试；
- 核查现有债权人同意、交叉违约和新增担保能力。

### 15.3 可转债及混合工具

- 识别转换价格、估值上限、折扣、到期、利息、赎回和控制权影响；
- 评价会计分类、潜在稀释和不同情景的经济分配；
- 检查与现有股东权利、未来融资和回购安排的冲突。

## 16. DDQ交付和教学规则

### 16.1 DDQ分层

将问题分为：

- **首轮资料**：交易方案、公司记录、三年及最新财务、审计税务、重大合同、预算预测、商业计划和系统数据；
- **第二轮解释**：针对趋势、差异、权利、估值和内部控制的管理层说明；
- **异常追加**：仅由已识别风险触发的穿透资料、样本、第三方证据和专家程序；
- **交割或投后事项**：同意、整改、留任、系统、报告和持续承诺。

### 16.2 每个问题必须解释

`问题 → 要证明的交易命题 → 需要的证据 → 怎样验证 → 什么回答不足 → 下一步`

不得把“请提供全部资料”当作有效 DDQ，也不得将管理层解释当成独立证据。

### 16.3 并购与融资差异

| 事项 | 并购买方重点 | 股权融资重点 | 债务融资重点 |
| --- | --- | --- | --- |
| 权利 | 控制权、资产边界、交割 | 稀释、保护性权利、退出 | 抵押、担保、契约和追索 |
| 财务 | 盈利质量、营运资金、净债务 | runway、里程碑、增长质量 | 偿债现金流、契约余量 |
| 估值 | 购买价及协同 | pre/post-money及分配瀑布 | 利率、期限和回收 |
| 合同 | 控制权变更及同意 | 新投资人权利冲突 | 限制性条款和交叉违约 |
| 交易后 | 整合、TSA、Day 1 | 治理、报告和下一轮融资 | 监控、合规和偿债 |

### 16.4 风控—答辩问题

在第三轮内部复核中至少挑战：

1. 为什么当前数据足以支持估值或融资金额？
2. 哪项正常化调整最容易被高估，反证是什么？
3. 哪项债务、类债务、稀释或特殊权利可能被遗漏？
4. 哪个合同、人员、许可或系统在交易后最可能失效？
5. 若预测下调、交割延迟或下一轮融资失败，交易结论是否改变？
6. 哪项风险应通过价格、交割条件、赔偿、分期出资或契约解决，而不是只靠“继续核查”？

答辩必须区分已确认事实、合理推断、未取得证据和拟执行程序，并形成教学型纪要。
