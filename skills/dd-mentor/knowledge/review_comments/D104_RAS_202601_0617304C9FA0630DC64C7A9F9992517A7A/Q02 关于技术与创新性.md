1、EB 固化是否为涂料油墨行业的新一代技术路线，目前市场占有率及变
动趋势，行业新增产能情况
EB 固化技术即电子束固化技术，是一种利用电子束作为能量源，引发涂料、
油墨、胶粘剂中的化学成分快速聚合交联从而实现从液态到固态的瞬间转变的
工艺。
EB 固化具备成为涂料油墨行业新一代技术路线的核心优势，具体体现在以
下几方面：（1）从环保特性看，EB 固化技术无需添加稀释溶剂和光引发剂，
零 VOCs 排放，且固化过程能耗低，属于环保节能降碳的绿色工艺。得益于此，
EB 固化技术可应用于食品、药品等对安全、环保等要求严格的包装印刷领域；
（2）相较于 UV 固化技术，EB 固化技术涂层的交联密度更高，在硬度、耐磨
损、耐化学腐蚀等性能上更有保障。优异的性能能够满足汽车零部件、电子器
件等高端制造业领域的要求。其次，EB 固化的电子束穿透力更强，固化速度极
快，显著提高生产效率，且不受涂层颜色和厚度的限制，能均匀固化厚涂层或
复杂形状工件（如异形件、深孔件）；（3）EB 固化过程几乎不产生热量
（“冷固化”），可适配热敏性基材（如塑料、纸张、薄膜），避免传统热固
化导致的基材变形、老化问题。
EB 固化技术落地仍具有挑战性，主要包括 EB 固化技术的推广离不开 EB
固化专业化设备，目前 EB 固化核心设备投资和维护成本较高，EB 固化涂料配
方需精准选择适合的原材料，但适用于 EB 固化的专用树脂、单体等原材料品
类较少，同时还需要下游客户根据各应用场景完善其工艺条件，从而达到最佳
施工性，才能最大程度体现 EB 固化技术独特的性能优势。上述挑战需要多方
投入较多的资金与协同，且需进行大量的试验和验证工作。目前，EB 固化技术
正在推广中，EB 固化产品市场占有率整体较低，我国 EB 固化市场的新增产能
也较少。根据公开资料显示，安徽省黄山尚傅科技有限公司（黄山永佳集团股
份有限公司的全资子公司）投资建设“年产 15000 吨 EB 固化涂料和 5000 吨无

（1）UV 固化、UV 树脂的技术难度体现及关联性
UV 固化技术难点主要体现在材料、光源和工艺三者的深度协同需求。原
材料的选择和设计决定了需要搭配哪种光引发剂；光引发剂的类型又必须与所
用紫外线光源的波长精准匹配；而光源的选择和照射等工艺方式（强度、时间、
角度）则直接关系到最终的固化效果和涂层性能，如光照不足会导致阴影区域
固化不完全，过度照射会加快涂层老化，且氧气干扰会显著降低固化效率。

UV 树脂作为涂料油墨的最主要原材料之一，其直接决定涂料油墨的物理/
机械性能。UV 树脂的技术难度主要体现在为满足不同下游应用领域的场景要
求，UV 树脂的选择或设计需精准适配多重需求，如 UV 树脂既要保证快速固化
反应，又要使涂层具备足够的坚韧性，还要能牢固附着在不同基材表面并提供
装饰性和功能性要求；针对 ABS、PC、PET、PP、玻璃、金属等不同基材，需
通过调整树脂结构，确保涂层与基材之间的附着力稳定。
UV 固化技术和 UV 树脂的关联性主要体现在 UV 树脂作为 UV 固化技术中
的最主要原材料之一，UV 树脂的选择或设计影响着 UV 固化技术的光引发剂的
选择，进而关系到最终的固化效果和涂层性能。因此，UV 树脂是 UV 固化技术
的基础，UV 固化技术与 UV 树脂的协同是决定最终性能的重要环节。
（2）UV 涂料油墨的技术难度是否主要依赖于原材料 UV 树脂
UV 涂料油墨主要由四类原材料组成：以树脂为代表的成膜物质、溶剂
（分散介质）、颜填料和助剂。树脂虽然是 UV 涂料的主要组成部分，但 UV
涂料的技术难度并非主要依赖于原材料 UV 树脂。
作为成膜物质的树脂（如聚氨酯类、丙烯酸酯类、环氧类等）虽为涂料提
供基础框架，但涂料性能需通过多组分协同才能达到最佳效果。单一大分子量
树脂粘度大、润湿和流平差，需要搭配其他助剂以获得良好的漆膜表观。
溶剂等分散介质的技术价值同样重要。活性稀释剂不仅需调节涂料粘度以
适配喷涂、淋涂等不同工艺，更要通过官能团数量平衡固化速度与涂层内应力，
单官能团稀释剂可降低交联密度以减少开裂风险，多官能团则能提升固化效率，
这种效率和稳定性的平衡设计，对配方体系的整体要求远高于对树脂性能的依
赖。
颜填料作为涂料中赋予外观特性与重要功能的关键组分，既通过颜料实现
涂层的着色（有机颜料色彩鲜艳、着色力强），适用于装饰性场景，又可以提
高涂层的遮盖力；颜填料还可以增强涂层耐磨性、耐化性等理化性能并实现成
本优化。
助剂的精准选用是解决涂料生产以及客户使用过程中痛点问题的核心。通
过添加消泡剂降低生产过程中泡沫的产生，提高了生产效率，且不能影响涂层

47
其他性能；添加流平剂增加涂料对基材的润湿、流平、表面滑爽度，减少漆膜
缩孔、橘皮、加色发花等缺陷，提高产品良率。这些助剂的选择需考量与树脂、
单体的相容性，以及对最终性能的影响。
综上，UV 树脂是 UV 涂料油墨技术的重要原材料，其决定了涂层材料的物

配，到分散介质与固化工艺的动态平衡，再到颜填料的预处理和分散，每个环

2、相关技术门槛及拓展难度
（1）树脂行业技术门槛
功能性树脂开发需要综合运用高分子化学、化学工程、表面物理等多学科
知识与技术。树脂行业技术门槛主要体现在分子设计、工艺复杂度等方面。树
脂行业技术核心是分子结构设计，需通过精准设计单体种类（如丙烯酸酯、环
氧、聚氨酯等）、官能团数量与分布、分子量及分布，从根源上定义树脂的性
能（如硬度、柔韧性、耐候性、反应活性等）。树脂行业核心工艺是聚合反应
过程的精确控制，涉及高温/高压反应、催化剂选择、反应速率调控等。
（2）涂料行业技术门槛
树脂合成企业向涂料领域延伸，面临较高的技术门槛与难度。核心在于涂
料配方并非多组分的简单物理混合，而是从单一组分设计到多体系协同，再到
场景化适配，这需要对配方中主要原材料进行合理选择与巧妙搭配。以 UV 涂
料为例，UV 涂料配方的复杂性构成了树脂企业向涂料领域延伸的核心技术壁
垒。
首先，引发体系的选择是基础难题。如光引发剂需精准匹配光源波长，同
时避开树脂、色浆等组分的吸收波段，而颜填料的干扰会进一步增加匹配难度。

51
其次，树脂体系的选择需实现多性能平衡。环氧丙烯酸酯、聚氨酯丙烯酸酯等
不同类型 UV 树脂，需从成膜性、反应活性、附着力、展色性等多维度筛选，
既要通过树脂分子结构提供涂层主体机械性能（如硬度、柔韧性），还要兼顾
反应活性、基材附着力等，任一性能的失衡都会导致整体失效。再次，光固化
单体的设计同样关键，单体的选择直接影响体系粘度、固化速度与涂层性能，
需根据配方需求精准调控单体种类与比例，以满足不同产品性能、适配不同施
工工艺。此外，涂料配方还需满足整体稳定性、环保合规性与工艺适配性等要
求。
除技术壁垒外，涂料油墨企业与树脂厂商的跨领域延伸，拓展难度还体现
在市场与客户资源、人力资源与经营管理等方面。市场与客户资源层面，跨领
域拓展的难度在于客户群体与需求逻辑发生转换，需从原有客户体系转向全新
群体，重建信任与合作基础，需突破存量市场的竞争壁垒，新品牌面临渠道与
份额争夺的多重阻力。人力资源层面，需重新组建人才结构与组织体系，补充
跨领域核心人才梯队，两类行业人才知识体系差异较大，招聘与培养成本较高。
经营管理层面，跨领域延伸的核心难度在于行业经验认知不足与管理能力的欠
缺，导致原有管理模式与新业务不匹配，无法准确识别市场走向。

（1）树脂改性对产品性能、生产效率的具体作用

酸酯丙烯酸树脂，针对性解决了厚涂层施工中触变性与柔韧性难以兼顾的问题，
传统树脂在厚涂层下易出现开裂或流挂，而改性树脂通过分子结构调整及与体
系中其他成分的协同作用，既增强触变性以适应厚涂层施工，又保持柔韧性以
抵抗外力损伤。针对饱和聚酯树脂（丰满度好、光泽高但固化慢）与羟基丙烯
酸树脂（硬度高、固化快但丰满度低）的特性短板，公司通过合成反应对两者
进行分子链间的接枝改性，实现了两类树脂的性能优势互补。汽车内外饰涂层
材料技术通过树脂改性、配方优化及精确配比等，在保证高光泽度的同时，提

料复合技术和配方设计，使得涂层呈现出高金属质感和仿电镀工艺的镜面效果。

点上也发挥着关键作用。针对 UV 树脂低能量固化慢和坚韧平衡性差的问题，
公司通过树脂结构设计，采用合理的化学反应，在树脂中引入对光敏感高的活
性基团，使树脂具有快速固化特点，即使在低能量光照条件下也能迅速交联成
网状结构。其次，通过对连接活性基团的链段进行优化，设计了末端分散结构，
有效解决树脂固化后硬度高、韧性差的问题。UV 涂料固化过程中存在氧阻聚
现象（氧气会降低固化效率），在加色体系中该影响更为明显，树脂改性技术
可对此类问题进行优化。例如，颜料表面吸附的空气会影响固化速度，公司通
过对面漆树脂改性减小其表面张力，颜料与树脂界面间的残留空气减少，氧阻
聚作用减弱，固化速度加快，同时涂层表面的耐磨性和抗划伤性能也得以提升。
涂料生产过程中，通过对环氧树脂改性，降低其粘度，同时适当提高官能
度。改性后树脂粘度显著下降，简化了涂料生产中的加热步骤，提升生产效率，
减少有机溶剂的使用，从而降低 VOC 排放。

3、访谈发行人核心技术人员、公开渠道查询，了解 UV 固化、UV 树脂的

脂；分析原材料、特种设备对发行人推出 EB 固化产品的预计影响。

（二）核查意见
经核查，保荐机构、申报会计师、发行人律师认为：
1、发行人涂料、油墨产品主要采用 UV 固化方式为主；发行人相关占比情
况与各领域常用固化方式相匹配，发行人采用的固化技术系相关领域的主流技
术。
2、EB 固化具有成为涂料油墨行业的新一代技术路线的核心优势，属于新
一代技术路线的发展方向；目前，EB 固化产品市场占有率整体较低，我国 EB
固化市场的新增产能较少；发行人通过技术研发与人才培养并行、推动应用技
术产业化等有效措施跟进新技术发展，积累了扎实的技术储备。
