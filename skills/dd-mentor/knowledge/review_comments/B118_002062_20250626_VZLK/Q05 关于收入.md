1）收入变动分析

报告期内，大型 PLC 的收入规模由 2022 年度的 6,415.83 万元增长至 2024
年度的 11,444.56 万元，中型 PLC 的收入规模由 2022 年度的 2,792.26 万元增
长至 2024 年度的 7,166.78 万元，大型 PLC、中型 PLC 是驱动整体收入规模增长
的最核心因素。小型 PLC、NARTU 的收入规模及占比整体均较低，各期收入金额
分别在 2,000 万元、1,000 万元左右。 
2）销量变动分析 
销量方面，大型 PLC、中型 PLC 与小型 PLC 的销量结构存在不同特点。中大
型 PLC 在产品模块结构、数量关系方面均基本一致，小型 PLC 模块类型较为简
单。具体分析如下： 
①大型 PLC 通常由 CPU 模块、模拟量 I/O 模块、数字量 I/O 模块、通讯模
块和电源模块等五大类模块，以及部分其他特殊功能模块构成。CPU 模块是核心
计算功能的实现载体，CPU 模块与模拟量 I/O 模块、数字量 I/O 模块与的合计配
比量在 1:6 左右，CPU 模块与通讯模块的配比量在 1:1 左右，CPU 模块与电源模
块的配比量在 1:2 左右，与复杂工况下 I/O 点数较高、独立通讯功能要求较高、
控制设备功率较大的特点相匹配。 
②中型 PLC 的功能模块结构与大型 PLC 一致。CPU 模块与模拟量 I/O 模块、
数字量 I/O模块的合计配比量在 1:5 左右，CPU 模块与通讯模块的配比量在 1:0.5
左右，CPU 模块与电源模块的配比量在 1:1 左右。与大型 PLC 相比较而言，中型
PLC 带点数会相对较少，因此 I/O 模块、CPU 模块与通讯模块的配比关系会略低
于大型 PLC。 
③小型 PLC 的功能模块结构就较为简单，主要由 CPU 模块、数字量 I/O 模
块和模拟量 I/O 模块构成。CPU 模块与模拟量 I/O 模块、数字量 I/O 模块的合计
配比量在 1:1.5-1:2 之间，其适用工况对 I/O 点数的要求与大型 PLC、中型 PLC
存在明显差异，并且对独立通讯、供电的要求较低，通讯模块、电源模块的销
售金额及占比均较小。 
3）均价变动分析 
均价方面，①大型 PLC 的 CPU 模块均价最高，在 12,000 元至 15,000 元左
右，中型 PLC 的 CPU 模块均价在 6,000 至 8,000 元左右；②其他模块大型 PLC

与中型 PLC 的系列销售均价则无明显差异，模拟量 I/O、通讯模块的均价均在
3,000 元左右，数字量 I/O 模块的均价均在 1,500 元左右，电源模块的均价均在
1,000 元左右；③小型 PLC 的价格体系与大型 PLC、中型 PLC 差异较为明显，CPU
模块的均价在 1,000 元左右，模拟量 I/O 的均价在 500 元左右，数字量 I/O 模
块的均价在 300 元左右，价格区间相对较低。 
均价变动方面，各模块在不同年度之间的均价变动，整体较为平稳。”

（一）NARTU
RTU（Remote Terminal Unit，远程测控终端）是一种用于监视、控制与数据
采集的远程控制终端，具有数据采集、存储、控制输出、通信等功能。相较于
PLC 产品，RTU 在使用中较少涉及控制逻辑决策、数据分析等功能，更多用于
数据采集、定期传输等用途。发行人的 NARTU 产品主要用于石油石化领域，在
油田井口实现对采油机上的无线传感器的数据进行采集，并定期与井场控制中心
通信进行数据上传。
