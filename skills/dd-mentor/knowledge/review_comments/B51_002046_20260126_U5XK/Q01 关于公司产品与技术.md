## 问询

1.1 关于公司产品 
根据申报材料：（1）公司主要产品包括面向桌面 PC/嵌入式计算平台的“开
先”系列通用处理器、面向服务器领域的“开胜”系列通用处理器及配套芯片产
品；（2）经与境内主要 CPU 厂商同期可比产品的技术指标比较，发行人认为公司
桌面 PC 产品处于国内领先水平，服务器产品可满足用户对于可用性、可靠性、安
全性及可服务性等多方面的产品需求。发行人用于技术指标比较的 KX-7000 系列
产品并非报告期内的主销产品。 
根据公开资料：部分比较竞品（如海光 5380、intel i5 系列产品）并非同行
业公司最新产品及高端产品；部分关键技术指标未涵盖，如产品制程、功耗、单
核性能、多核性能等。 
请发行人披露：（1）区分公司各系列处理器产品及配套芯片，列式其推出时
间、各期收入及占比、单价和毛利率等情况，各类型产品是否存在技术难度梯度
关系或高中低端划分；（2）比较分析发行人与境内外主要 CPU 厂商的核心技术掌
握情况和技术迭代情况；是否选取了同行业公司最新或主流产品用于技术指标比
较，技术参数选择是否合理、全面；结合前述比较情况客观分析公司产品的技术
先进性和技术优势，并在招股说明书中针对性完善相关披露。 
请保荐机构简要概括核查过程，并发表明确意见。

从生态架构层面看，兆芯集成和海光信息的产品能够兼容 x86 指令集，华

x86 架构处理器在重点行业市场的份额低于国内整体市场，主要原因包括：
（1）生态兼容性是用户选择处理器架构类型的重要参考因素，开放市场主要遵
循商业竞争规律，对产品生态兼容性和用户使用体验的要求更高，x86 架构处
理器凭借成熟完善的生态占据了主要市场份额；重点行业市场根据最终应用场
景的不同，对于生态的需求度略有区别。以金融行业为例，金融行业的使用者

对应用软件的丰富性、多样性有更高需求，对 CPU 处理器的生态兼容性要求较
高，因此 x86 架构处理器在金融行业的份额趋近于开放市场；而部分重点行业
领域的政策驱动因素较强，在政策层面鼓励技术路线的多元化，对生态兼容性
的要求略低。（2）国内重点行业市场中党政领域起步较早，并主要依靠政策和
财政资金的支持，市场化程度整体上低于其他行业领域。随着重点行业市场国
产替代逐步向金融、教育、能源等更多行业领域发展，行业用户将更加重视
CPU 的软硬件生态丰富度、兼容性以及更低的国产化迁移成本；（3）桌面 PC
领域对软硬件生态丰富度和兼容性有着更高要求，因此 x86 架构在桌面 PC 重点
行业市场的市场份额整体上高于服务器领域。在服务器重点行业市场中，采用
ARM 架构的华为海思起步较早，具备先发优势，在国内 CPU 厂商中占据了较
高市场份额。
（3）重点行业市场未来发展趋势
1）国家支持政策频出，加速重点行业市场 CPU 发展
重点行业市场对信息安全、供应链安全要求较高，是国产 CPU 的优势市场，
基于国产 CPU 的整机产品已经在重点行业市场得到批量应用。在国家政策的大
力支持下，重点行业市场有望加速发展，驱动 PC 和服务器市场 CPU 需求的持
续增长。根据亿欧智库的预测数据，2024 年至 2027 年桌面 PC 重点行业市场
CPU 出货量年均复合增长率预计为 33%-37%，2024 年至 2027 年服务器重点行
业市场 CPU 出货量年均复合增长率预计为 14%-16%。
2）重点行业市场从党政领域替代逐步拓展至更多行业领域，对 CPU 的生
态适配度提出了更高要求
重点行业市场中党政领域起步较早，并主要依靠政策和财政资金的支持。
当下，重点行业市场替代正逐步向金融、教育、能源等更多行业领域发展，对
于行业用户而言，由于国家财政补贴支持较小，因此其一方面将更加注重产品
性能，另一方面要求 CPU 产品具备更高的生态适配度以及更低的国产化迁移
成本。
因此，生态构建将是未来重点行业市场完成国产替代的重要内容，尤其是
在对软硬件生态丰富度和兼容性有着更高要求的桌面 PC 领域，如何帮助用户

实现低成本的国产化迁移是衡量 CPU 厂商核心竞争力的关键因素之一。从目前
各 CPU 厂商的生态构建情况来看，x86 指令集架构拥有成熟完善的应用生态，
在国产替代过程中无需付出额外的应用迁移和改造成本；以华为海思和飞腾信
息为首的 ARM 架构生态亦日益完善；其他指令集架构的生态尚需进一步完善，
仍需付出长期努力。

（2）开放市场竞争格局
1）桌面 PC 领域，国内各 CPU 厂商目前均主要在重点行业市场进行销售，

国外厂商占据了桌面 PC 开放市场的绝大多数（超过 99%）市场份额
从桌面 PC CPU 整体市场的竞争格局看，基于亿欧智库以及 Canalys 的统计
数据进行测算，2024 年国产 CPU 厂商已占据国内桌面 PC CPU 整体市场 10%左
右的市场份额，桌面 PC CPU 国产化率从 2022 年的 4%提升至 10%，但国内
CPU 厂商仍主要通过参与重点行业市场获取市场份额。
从桌面 PC CPU 开放市场的竞争格局看，Intel、AMD 等国外厂商占据开放
市场的绝大多数（超过 99%）市场份额，国产 CPU 厂商目前主要参与重点行业
市场，开放市场仍处于前期探索阶段。国产 CPU 厂商中，公司桌面 PC 处理器
性能优异并兼容开放市场的主流 x86 生态，且市场应用领域不受限制。报告期
内，公司芯片产品在教育领域 OPS 产品、工业 IPC 整机以及企业网安产品等开
放市场实现部分出货，报告期内累计销售约 15 万颗，主要客户群体为工业企业、
教育院校等，上述客户当前并未有国产化政策采购要求，主要系出于产品性能、
性价比等考虑采购公司处理器产品。同时，根据公开信息，2025 年华为发布采
用“鸿蒙操作系统+麒麟芯片”的鸿蒙 PC，计划逐步参与桌面 PC 开放市场竞
争。其他国产 CPU 中，尚未有明确的桌面 PC 开放市场拓展信息。
生态架构层面，根据亿欧智库的统计数据，2022 年中国 PC 市场 x86 架构
（主要为 Intel 和 AMD）占比为 93%，ARM 架构（主要为苹果公司）占比为

随着苹果、华为等整机厂逐步采用自研 ARM CPU 芯片参与 PC 市场竞争，预计
未来 ARM 架构 PC 占比将进一步提升。服务器领域，根据 IDC 的统计数据，
2025 年上半年 ARM 架构（主要为华为海思）市占率合计为 19%，呈现上升趋
势。
3）随着国产替代的不断进行，国产 CPU 厂商的市场份额仍将逐步上升
国内开放市场存在较高的产品生态与性能壁垒，并以 Intel 和 AMD 为主。
国产 CPU 厂商由于经营规模、人才资源、研发投入规模等劣势，目前在开放市
场的市占率仍有较大提升空间。随着国产 CPU 厂商产品性能逐步提升并实现应
用落地，对国产 CPU 的需求预计将逐步提升，国产 CPU 厂商的市场份额未来
亦将逐步提升。

2）国内 CPU 企业在技术路线、技术来源和技术水平方面存在一定差异
①技术路线、技术来源方面
由于产品定位和技术来源不同，国内六家 CPU 厂商采取了不同的技术路线，
不同技术路线导致各家厂商在生态构建、发展布局等方向具有较大的差异。兆
芯集成和海光信息的产品能够兼容 x86 指令集，华为海思和飞腾信息的产品兼
容 ARM 指令集，龙芯中科和电科申泰的产品分别采用 LoongArch 指令集和
SW-64 指令集。
②技术水平方面
国内 CPU 企业在产品布局和市场侧重点方面有所不同，因此在不同的市场
领域各 CPU 企业的技术水平存在差异。
桌面 PC 领域，在桌面 PC 应用场景注重的单核及多核整数性能方面，公司
于 2023 年底推出的 KX-7000 处理器相比同行业可比公司龙芯中科、飞腾信息
分别于 2023 年、2024 年发布的最新一代桌面 PC 处理器产品具有优势。同时，
根据海光信息官网披露，其于 2025 年 7 月首发最新一代海光四号 3000 系列工
作站处理器整机，产品性能国内领先。服务器领域，海光信息和华为海思的处
理器性能在国内处于领先地位，公司为服务器市场的追赶者，KH-40000 处理器

1、AI 时代下 CPU 领域的最新发展趋势
（1）CPU 是 AI 算力平台不可或缺的控制“大脑”，AI 将带动 CPU 市场
需求持续增长
在 AI 浪潮全面重塑算力需求的时代，CPU 产业正由“通用计算”向“智
能计算”发展。在 AI PC、AI 服务器等各类 AI 算力平台中，CPU 是不可或缺
的控制“大脑”。
桌面 PC 领域，AI 技术驱动终端行业加速变革，AI PC 正成为桌面 PC 市场
新的发展方向，并将带动新一轮 PC 换机需求，为桌面 PC CPU 市场带来新的增
长源。2025 年 8 月 27 日，国务院发布《关于深入实施“人工智能+”行动的意
见》，提出大力发展智能网联汽车、人工智能手机和电脑、智能机器人、智能
家居、智能穿戴等新一代智能终端，打造一体化全场景覆盖的智能交互环境。
AI PC 的发展有望带动 PC 行业步入新一轮发展周期，从而带动桌面 PC 市场
CPU 出货量的增长。根据 Canalys 的统计数据，2024 年中国大陆 AI PC 的出货
量在 2024 年实现了稳步增长，达到 580 万台，占中国大陆 PC 总出货量的 15%。
服务器领域，目前服务器市场呈现通用服务器和 AI 服务器并重的发展态势，
而服务器 CPU 是通用服务器和 AI 服务器均不可或缺的重要算力来源，其中通
用服务器由 CPU 作为单一算力来源，AI 服务器由 CPU 和 GPU 等其他专用芯片
组成的异构计算体系共同提供算力来源。受益于 AI 和算力市场发展的推动，AI
服务器市场出货量持续增长，同样带动了服务器 CPU 市场需求的增长。中商产
业研究院的数据显示，中国 AI 服务器市场出货量由 2022 年的 28.4 万台增长至
2024 年的 42.1 万台，2024 年同比增长 18.93%。
（2）AI 时代，CPU 的角色转变为“通用计算核心+任务调度与协同中枢”

AI 时代，通用处理器平台转变为 AI 算力基座，普遍采用“CPU 通用芯片
+ GPU/NPU 等其他专用芯片”的异构计算体系，CPU 的角色转变为“通用计算
核心+任务调度与协同中枢”。CPU 一方面负责 AI 任务的初始化、数据预处理
以及任务结果处理和应用，另一方面负责整个 AI 工作流的调度、协调和控制，
而 GPU/NPU 等专用芯片则是在 CPU 的指挥下，专注于执行大规模并行计算。
在 AI 任务处理中，一方面 CPU 芯片的性能和效率直接影响整个 AI 系统的
计算效率和响应速度，因此需要 CPU 芯片具备较高的计算性能；另一方面，
CPU 通过互连总线与 GPU/NPU 等其他专用芯片进行数据交互，这要求 CPU 具
备更优异的异构多核互连能力、更高的互连带宽以及支持更先进的 PCIe、DDR
等高速互连接口等，从而与 GPU/NPU 等其他专用芯片更好地协同工作。

三、全面评估地缘政治及国际贸易形势可能对公司技术研发及产供销等方

（一）全面评估地缘政治及国际贸易形势可能对公司技术研发及产供销等
方面的影响，是否存在有效的应对安排
报告期内，地缘政治及国际贸易形势对公司技术研发及产供销未产生重大
不利影响。公司当前的技术研发、原材料采购、芯片制造以及产品销售等主要

近年来，美国多次对中国大陆半导体产业采取不同程度的出口管制措施，
且同行业可比公司存在被列入美国“实体清单”的情况。未来，若出现国际贸
易形势和地缘政治发生重大不利变化、美国加大对中国大陆半导体产业的出口
管制或公司未来被列入美国“实体清单”等外部原因，将对公司技术研发及产

供销等方面产生不利影响。针对上述情况，公司已采取有效措施加以应对，具

1、关于技术研发
地缘政治及国际贸易形势对 CPU 企业在技术研发方面的影响主要包括 IP

CPU 芯片设计涉及处理器内核 IP、互连接口 IP、内存控制器 IP 等多种 IP
工具。处理器内核 IP 方面，公司具备自主研发 CPU 内核微架构的能力，处理
器内核 IP 均由公司自主研发形成。CPU 其他核心 IP 方面，DDR PHY、USB 
PHY、Serdes 等互连接口 IP 以及 DDR 控制器、PCIe 控制器、SATA 控制器、
USB 控制器等内存控制器 IP 均来自公司自主研发。
综上，公司具备 CPU 核心 IP 的自主设计研发能力，不依赖外部第三方供
应商，不受美国技术限制，预计地缘政治及国际贸易形势对公司 IP 工具采购的
影响较小。
（2）EDA 工具
EDA 工具市场主要提供方为新思科技、楷登电子和西门子等美国厂商。
2025 年 5 月，美国商务部要求三家 EDA 工具厂商停止向中国客户提供 EDA 软
件和技术支持。2025 年 7 月，美国商务部已解除对中国市场的 EDA 出口限制。
公司目前与上述 EDA 供应商建立了稳定的合作关系，未发生过合作纠纷，
且不存在潜在纠纷。除不可抗力因素外，发行人与上述 EDA 供应商不能续约的
风险较小。若未来继续出现美国对中国市场全面进行 EDA 出口限制的情况，国
内公司 M、概伦电子等 EDA 厂商能够在部分环节实现国产替代，但部分产品
仍需进一步完善，且切换 EDA 供应商将产生额外成本，将对公司产品研发进度、
研发成本等造成不利影响。
随着我国半导体产业相关技术水平的不断提升，产业生态的日益完善，国
内 EDA 厂商的产品也将持续完善。同时，公司亦积极与国内 EDA 厂商展开合
作，并参与国内 EDA 产业生态的构建和完善。

四、中介机构核查意见
（一）核查程序
保荐机构及发行人律师进行了如下核查：
1、访谈发行人相关负责人，了解发行人核心技术的形成及演变过程，消化
吸收引进技术的具体情况；
2、获取并查阅发行人历代产品的主要性能参数，对比分析发行人关键产品
参数的演变及提升情况；
3、查阅发行人及子公司已取得的发明专利、软件著作权、集成电路布图设
计专有权等技术成果以及核心技术列表；查验发行人及子公司取得的相关专利
证书等无形资产证明文件及国家知识产权局出具的专利登记簿查询证明；取得

发行人与 EDA 供应商、IP 供应商、晶圆厂等主体订立的技术许可相关协议；访

中国执行信息公开网等网站查询发行人是否存在相关知识产权纠纷；
4、查阅发行人报告期内委外研发支出明细，获取报告期内发行人委外研发
的合作协议，了解委外研发的合作背景及具体内容，分析委外研发活动具有必
要性、合理性和公允性；
5、查询相关行业报告及行业政策，访谈发行人相关负责人，了解地缘政治
及国际贸易形势可能对公司技术研发及产供销等方面的影响，以及公司针对上
述影响的应对措施；查阅招股说明书，复核发行人相关风险揭示情况。
