曜持）共同设立格兰菲（2024 年净利润-43,726.46 万元）；2020 年 11 月，联
和投资出具批复同意本次分拆；分拆后，公司向格兰菲采购集成显卡 IP 和技
术服务；（2）发行人 2022 年长期股权投资会计差错更正-17,960.58 万元；

## 回复

一、发行人分拆 GPU 业务后又向格兰菲采购集成显卡 IP 授权的具体原因
及决策过程，结合公司产品构成、业务规划及与格兰菲的关联采购情况，说明
分拆 GPU 业务背景、必要性及合理性，是否符合行业发展趋势，是否履行了
完备的国资审批程序
（一）发行人分拆 GPU 业务后又向格兰菲采购集成显卡 IP 授权的具体原
因及决策过程
发行人基于业务发展等角度考虑剥离 GPU 业务后（具体参见本题之“一、
发行人分拆 GPU 业务后又向格兰菲采购集成显卡 IP 授权的具体原因及决策过
程，结合公司产品构成、业务规划及与格兰菲的关联采购情况，说明分拆 GPU
业务背景、必要性及合理性，是否符合行业发展趋势，是否履行了完备的国资
审批程序”之“（二）结合公司产品构成、业务规划及与格兰菲的关联采购情
况，说明分拆 GPU 业务背景、必要性及合理性，是否符合行业发展趋势，是否
履行了完备的国资审批程序”），与 GPU 相关的人员与技术均已剥离，后又向
格兰菲采购集成显卡 IP 授权存在商业上的合理性和必要性：
1、搭配集成显卡能够更好满足目标市场终端用户需求
作为将数字信号转化为可视图像的关键硬件，显卡是现代电脑必要组成部
分。CPU 负责逻辑运算，但面对海量图形处理时效率低下，显卡 GPU 拥有数千
个计算核心，专为并行处理设计，无论是渲染游戏光影、解码 4K 视频，还是

驱动操作系统界面，都依赖显卡实时完成。与搭配独立显卡相比，集成显卡在
功耗和成本方面均有较大优势，公司的桌面处理器在具备集成显卡后，能够在
图像处理能力、功能性、低功耗、性价比等方面更好的满足目标市场终端用户
需求，提高公司桌面处理器的竞争力。
2、格兰菲提供集成显卡 IP 的适配性更好且交付效率更高
2020 年公司剥离 GPU 业务并成立格兰菲后，公司在市场上筛选集成显卡
供应商，但当时国内其他 GPU 公司无法提供满足公司需求的一站式集成显卡 IP
交付的产品或服务，且当时均无桌面集成显卡产品成功应用案例及量产经验，
公司需采购不同供应商的不同 IP 产品及定制设计以完成集成显卡的开发。格兰
菲技术来源为 S3 Graphics，主要面向桌面 PC 领域和 x86 架构，过往针对 x86
架构通用处理器形成了许多面向桌面 PC 的量产化产品，因此适配性更好。同
时，格兰菲在接口标准、API、软件适配等方面积累了丰富的经验，能够提供有
效、便捷的技术支持服务。
公司董事会和股东大会已对向格兰菲采购集成显卡 IP 授权予以确认并审批。
（二）结合公司产品构成、业务规划及与格兰菲的关联采购情况，说明分
拆 GPU 业务背景、必要性及合理性，是否符合行业发展趋势，是否履行了完
备的国资审批程序
1、剥离 GPU 业务背景、必要性及合理性
公司 GPU 业务经过多年发展，已经确立了一定的市场基础和发展路径，国
内也逐步产生了对 GPU 产品的市场需求，但彼时 GPU 团队仅作为内部支持部
门，无法独立面向外部市场并开展业务，GPU 团队核心价值无法充分发挥。如
果再继续与单一的 CPU 固定绑定，局限在集成显卡的渲染功能，将极大地限制
GPU 的技术创新，产品迭代和市场开拓。为抓住潜在的市场需求，并发挥 GPU
团队的潜力，改变原先仅作为内部支持部门的定位，使其独立面向市场开展业
务，公司于 2020 年 6 月召开董事会，同意由公司、GPU 团队和外部战略投资机
构共同出资设立格兰菲，以实现 GPU 技术研发形成的集成显卡、独立显卡产品
能够独立面向市场的目的。同时，剥离该业务有助于公司聚焦 CPU 相关业务，
优化业务结构，最终保障公司股东价值的最大化。

公司在剥离格兰菲后专注于高性能处理器内核微架构设计技术、高性能处
理器多核互连架构技术等 CPU 芯片设计，分别于 2022 年末、2023 年末推出
KX-6000G、KX-7000 桌面处理器新产品，并于 2022 年末推出首款专门面向主
流服务器市场需求设计研发的 KH-40000 服务器处理器。格兰菲方面，其成立
后即开展了独立显卡的研发及流片并形成多代产品，逐步由成立之初主要为兆
芯集成提供集成显卡 IP 发展为目前以独立显卡为主集成显卡为辅的业务结构。
随着逐步自主开发新客户，销售独立显卡等新产品，格兰菲 2023 年度兆芯集成
的收入占比已下降至 35.84%，2024 年兆芯集成的收入占比进一步下降至
23.55%，格兰菲对兆芯集成的收入依赖程度大幅下降。
公司剥离 GPU 业务主要系从充分发挥 GPU 团队价值、发挥 GPU 团队潜
力、保障公司利益角度出发。目前格兰菲已完成多轮融资，格兰菲也已开发了
除兆芯集成以外的其他客户及产品类型，并于 2025 年 2 月 7 日完成了 IPO 辅
导备案，格兰菲具备市场化独立经营能力。综上，公司剥离 GPU 业务具有合
理性及必要性。
2、是否符合行业发展趋势，是否履行了完备的国资审批程序
长期以来，我国电脑显卡一直被英伟达、AMD 等外国企业垄断，国产
CPU 长期只能安装国外厂商的独立显卡，出于提升国家数据安全及网络安全的
需要，国产独立显卡自主研发问题需要得到有效解决。同时，由于 CPU 及
GPU 在构架及工作原理方面的差异，导致 GPU 这种并行处理架构在并行计算
方面有着更高的性能和效率，在科学计算、大模型训练和 AGI 推理方面有着独
特的优势，成为不可或缺的核心算力资源。
GPU 作为 AI 算力的最优选择，使得国内已逐步产生了对 GPU 产品的市场
需求，国内 GPU 创业公司大量涌现。其中，上海燧原科技股份有限公司成立于
2018 年，上海壁仞科技股份有限公司成立于 2019 年，摩尔线程智能科技（北
京）股份有限公司（以下简称“摩尔线程”）和沐曦集成电路（上海）股份有
限公司均成立于 2020 年，百度于 2021 年拆分 AI 芯片公司昆仑芯（北京）科技
有限公司。

（1）构成业务的相关定义
根据《企业会计准则解释第 13 号》，合并方在合并中取得的生产经营活动
或资产的组合（以下简称组合）构成业务，通常应具有下列三个要素：
1）投入，指原材料、人工、必要的生产技术等无形资产以及构成产出能力
的机器设备等其他长期资产的投入；
2）加工处理过程，指具有一定的管理能力、运营过程，能够组织投入形成
产出能力的系统、标准、协议、惯例或规则；
3）产出，包括为客户提供的产品或服务、为投资者或债权人提供的股利或
利息等投资收益，以及企业日常活动产生的其他的收益。
该组合能够独立计算其成本费用或所产生的收入，直接为投资者等提供股
利、更低的成本或其他经济利益等形式的回报。有关资产或资产、负债的组合
要构成一项业务，不一定要同时具备上述三个要素。

四、中介机构核查意见
（一）核查程序
保荐机构及申报会计师进行了如下核查：
1、查阅发行人采购格兰菲 GPU IP 及技术服务相关合同协议，并检查相关
技术交付成果；
2、获取并分析其他 GPU 厂商询价文件；
3、查阅海光信息、芯原股份、灿芯股份等同行业上市公司招股书及年报并
分析其业务模式及产品服务情况；
4、访谈格兰菲并了解其向发行人提供的产品服务相关情况；
5、查阅并复核格兰菲报告期财务报表及事务所间报告；

6、取得并复核格兰菲长投减值测试所涉资产评估报告。
（二）核查意见
经核查，保荐机构及申报会计师认为：
1、发行人 2023 年以来未继续采购格兰菲 IP 系下一代搭配集成显卡的桌面
处理器产品尚未正式立项，与发行人新产品研发匹配；报告期内发行人采购格
兰菲 IP 授权符合合同约定及行业惯例，发行人与格兰菲的集成显卡 IP 交易价
格系双方根据市场价格协商定价，根据询价结果，第三方提供的集成显卡 IP 组
合和格兰菲集成显卡 IP 定价具有可比性、公允性；
2、公司向格兰菲采购各项技术服务的行为符合行业惯例，公司不具备
GPU IP 相关技术服务能力，采购格兰菲技术服务与发行人技术服务内容不同、
定价原则不存在明显差异；发行人向格兰菲关联采购具有必要性、合理性及公
允性；
3、格兰菲各期经常性损益划分合理，未经审计不影响发行人财务报表准确
性；发行人对参股企业的会计处理准确；格兰菲报告期营收持续增长，由于研
发费用增加导致亏损，根据资产评估报告评估结果无需计提减值，对发行人未
来业绩的预计影响已经披露在招股说明书中，芯展科技未发生减值迹象，亦无
需计提减值。
