## 问询

根据申报材料，（1）发行人期间费用主要为销售费用和研发费用；（2）
销售费用主要为线上推广、广告宣传费和职工薪酬等，报告期内线上推广费用
逐年下降，2022-2024 年广告宣传费明显下降，销售费用率低于同行业可比公
司；（3）研发费用主要为职工薪酬。 
请发行人披露：（1）公司 B 端用户和 C 端用户具体的销售及推广方式，
销售人员及推广支出是否区分 B 端和 C 端，如有，分析人员工作内容及推广内
容的区别；（2）主要获客渠道，各渠道获客的分布情况，与同行业是否存在
差异；报告期初广告宣传费相关可抵扣暂时性差异的形成原因、核算准确性；
报告期内线上推广费和广告宣传费下降的原因及合理性；（3）推广费用金额、
推广获客数量与用户数、收入等经营及财务指标变动的对比情况；推广服务是
否存在地域性分布特征，与发行人收入地域性分布的匹配情况；（4）推广服
务的价格、充值及消耗情况，价格的公允性；（5）获客成本的变动情况，与
同行业是否存在差异；（6）公司销售人员平均薪酬低于可比公司销售人员平
均薪酬的原因，销售费用率低于同行业可比公司的原因；（7）推广费用的完
整性，是否存在其他方为发行人承担费用成本的情形；（8）结合发行人业务
开展及人员组织结构，说明生产活动与研发活动的区别，生产人员、销售人员、

（9）是否存在非研发人员从事研发活动的情形，人员工时归集方式及准确性，
研发与生产共用资源支出的分摊方法及依据；（10）研发人员平均薪酬低于可

差异，差异原因。

## 回复

一、公司 B 端用户和 C 端用户具体的销售及推广方式，销售人员及推广支
出是否区分 B 端和 C 端，如有，分析人员工作内容及推广内容的区别 
C 端用户主要通过发行人 App、网页端、小程序付费下单。针对 C 端用户，
公司产品主要通过移动端应用市场、信息流广告、网页端搜索引擎等线上渠道
推广。
B 端业务采用直接销售模式，通过自有销售团队开拓商机，并根据客户的
需求提出产品解决方案，此后由销售人员向客户进行报价，双方达成共识后拟
定销售合同并完成交易。针对 B 端用户，公司主要通过销售人员接洽潜在客户，
并策划展会、沙龙等活动推广产品。
除上述可直接对应至 C 端或 B 端用户的广告推广方式外，发行人还通过楼
宇、地铁广告等线下方式进行推广，触达更广泛的潜在或现有用户群体。
公司销售人员主要归属于运营中心、销售中心，少量归属于技术中心、国
际业务部，基于上述部门的销售人员所主要从事的工作内容，可以区分 B 端和
C 端，具体如下：
1、运营中心主要负责客服、内容审核、品牌服务、公关传播、渠道推广、
市场宣传、用户运营及推广等工作，主要服务 C 端客户；
2、销售中心主要通过自有销售团队进行市场营销工作。销售中心人员负责
寻找潜在客户，促进销售合同的达成、跟进后续回款并持续维系客户关系，主
要服务 B 端客户；
3、技术中心的售前技术支持组主要负责通过线上远程支持和现场服务等形
式，为客户提供高质量的技术支持，以促进销售达成，主要服务 B 端客户；
4、国际业务部主要负责海外市场的营销工作，主要服务 B 端客户。

（二）报告期初广告宣传费相关可抵扣暂时性差异的形成原因、核算准确
性 
根据《中华人民共和国企业所得税法实施条例》（中华人民共和国国务院
令第 512 号）第四十四条规定：“企业发生的符合条件的广告费和业务宣传费
支出，除国务院财政、税务主管部门另有规定外，不超过当年销售（营业）收
入 15%的部分，准予扣除；超过部分，准予在以后纳税年度结转扣除。”
公司存在可结转以后年度抵扣广告费产生的暂时性差异，系由于公司各年
在线上、线下渠道投入的市场宣传和推广费用超过当年营业收入的 15%形成的
暂时性差异。报告期之前，发行人收入规模相对较少，为提升品牌知名度与市
场竞争力，2019 年至 2021 年期间累计投入近 3 亿元推广费。同时，2021 年全
行业在营销端竞争激烈，公司所在商业大数据服务行业面临较大的增长和竞争
压力，竞争对手在广告投入方面投入大量资源。例如，根据合合信息招股说明
书，行业竞品启信宝 2021 年 C 端营业收入为 7,315.43 万元，对应 C 端推广费

用为 6,384.77 万元，推广费用率高达 87.28%。在此背景下，发行人亦加大了推
广费投入。因此发行人报告期初形成了大额的广告宣传费相关可抵扣暂时性差
异。结合报告期初审计报告进行复核、测算，发行人报告期初广告宣传费相关
可抵扣暂时性差异核算准确。随着公司品牌知名度提升，收入规模增长，推广
宣传费投入减少，暂时性差异于 2023 年开始缩小，预计未来可逐步消耗。
（三）报告期内线上推广费和广告宣传费下降的原因及合理性 
报告期内，公司线上推广费分别为 6,836.15 万元、6,238.70 万元、5,854.93
万元和 2,844.97 万元，广告宣传费分别为 2,527.97 万元、1,952.13 万元、295.12
万元和 500.07 万元。除 2025 年 1-6 月广告宣传费有所上升之外，整体呈下降趋
势，主要原因说明如下：
报告期内，公司在线上推广方面进行合理配置，不断优化线上广告投放策
略，动态调整推广节奏和方案，依靠不断提升的产品力培养和影响用户的使用
习惯，提升用户的产品使用体验，引导用户从注册到活跃再付费的良性转变，
从而导致线上推广费支出整体上呈下降趋势。
近年来，随着企查查会员类产品的注册及活跃用户规模不断扩大，企查查
的品牌知名度也不断提升，公司所提供的商业大数据产品及服务已逐步占据行
业主导地位，加之公司在地铁、电梯智能屏等线下广告媒介的选择和投放方面
日益积累了丰富经验，因此，公司在广告宣传策略进行了主动调整，在投放时
机、城市以及区域方面更加注重精细化，从而使得报告期前三年线下推广的开
支有所下降。2024 年，公司广告宣传费与此前年度相比降幅较大，主要系随着
数字媒体的发展伴以宏观经济的影响，整体线下广告市场回暖不及预期，线下
地铁广告、电梯智能屏广告上刊率较低。2025 年上半年，公司结合自身业务需
要和竞品线下投放动态，在春节后采用“梯媒+机场”的组合方案针对性地进行
线下媒介投放，使得当期广告宣传费同比有所提升。
综上，报告期内发行人线上推广费和广告宣传费整体上有所下降，与发行
人调整推广策略、提升推广效率相关，具有合理性。

（一）推广费用金额、推广获客数量与用户数、收入等经营及财务指标变
动的对比情况 
发行人的线下推广形式主要是地铁广告、电梯智能屏广告等，主要目的是
品牌宣传，难以匹配直接获客情况。相反，发行人的线上推广主要以移动端应
用市场、信息流广告、网页端搜索引擎等形式通过苹果、头条、华为、百度等
主流线上渠道进行投放，主要目的在于吸引新用户注册，如潜在用户通过线上
广告链接点击注册成为发行人用户，即可认定为线上推广对应的新增注册用户。
发行人进行线上推广获客时，主要目的在于吸引游客注册浏览，在获取了广泛
的注册用户存量的基础上，有深度使用需求的注册用户会根据自身需求选择进
一步购买付费产品。基于上述原因，相比于新增付费用户数，线上推广费用与
其对应的新增注册用户数的比例存在更强的匹配关系（即单位获客成本）。

方平台存量用户的争夺更为激烈，投入产出比有所下降，为维持产品曝光度，
公司需增加推广出价，直接推高了获客成本所致。

（二）采购价格公允性 
1、线上推广 
（1）第三方平台通常采取竞价广告的方式定价，平台设置底价，广告主考
虑广告位、投放量级、人群定位、排名等因素，在底价的基础上溢价出价，并
根据投放效果调整定价，平台根据实际点击次数、点击率、曝光时长、曝光次
数、下载次数、下载率等指标计算实际消耗金额并从充值金额中扣除。如
VIVO 广告平台投放的底价标准公开透明，对所有广告主一致，如广告主想获
得更多曝光度，需根据市场情况增加出价，定价过程能够体现市场竞争性。投
放页面和平台竞价规则页面如下图所示：

（2）如发行人与平台代理商合作，平台的竞价广告规则本身保持公开透明，
发行人通过比较不同代理商的充值优惠政策、服务条款，综合遴选条件最优的
供应商后签署合同、建立合作。
综上，基于第三方平台实施按竞价消耗账户余额的定价模式以及平台代理
商与发行人友好协商的充值优惠政策，发行人针对线上推广服务的采购价格具
有公允性。
2、线下推广 
发行人线下推广主要以电梯智能屏广告、地铁广告等为主，此类广告的价
格主要由城市等级、点位价值等因素决定。发行人主要与行业内知名广告供应
商合作，如分众传媒系国内梯媒龙头、德高广告系主流的交通媒体，交易价格
均为双方根据市场情况，通过商业谈判友好协商决定，定价具备公允性。
综上，发行人线下推广采购系基于价格、投放点位、供应商实力的综合考
量选择供应商，采购价格根据市场情况与商业洽谈决定，且供应商与发行人并
无关联关系，采购定价具备公允性。

扣除对其应纳所得税额无实质性影响，故未申报研发费用加计扣除；2022 年度
至 2024 年度差异金额分别为 580.88 万元、798.77 万元、799.51 万元。
（二）股份支付费用、福利费 
根据《财政部、国家税务总局、科技部关于完善研究开发费用税前加计扣

除政策的通知》（财税〔2015〕119 号）规定，人员人工费用指直接从事研发
活动人员的工资薪金、基本养老保险费、基本医疗保险费、失业保险费、工伤
保险费、生育保险费和住房公积金，以及外聘研发人员的劳务费用，发行人将
不符合上述定义的股份支付费用、福利费剔除，2022 年度至 2024 年度差异金
额分别为 165.58 万元、307.02 万元、195.55 万元。
（三）折旧摊销费、场地使用费 
根据《财政部、国家税务总局、科技部关于完善研究开发费用税前加计扣
除政策的通知》（财税〔2015〕119 号）规定，可加计扣除的直接投入费用、
折旧费用包括研发活动的仪器、设备的投入及折旧费等，与房屋相关的折旧摊
销费、场地使用费不满足上述定义，2022 年度至 2024 年度发行人剔除金额分
别为 140.94 万元、237.52 万元、603.69 万元。
（四）其他费用 
根据《财政部、国家税务总局、科技部关于完善研究开发费用税前加计扣
除政策的通知》（财税〔2015〕119 号）规定，与研发活动直接相关的其他费
用，如技术图书资料费、资料翻译费、专家咨询费、高新科技研发保险费，研
发成果的检索、分析、评议、论证、鉴定、评审、评估、验收费用，知识产权
的申请费、注册费、代理费，差旅费、会议费等。此项费用总额不得超过可加
计扣除研发费用总额的 10%。发行人基于谨慎性考虑，将部分办公费、通讯费
等剔除，2022 年度至 2024 年度发行人剔除金额分别为 35.26 万元、40.08 万元、
62.70 万元。
综上所述，发行人研发费用加计扣除金额与报表研发费用金额主要系会计
准则与税务法规间的核算口径差异，具备合理性。
十二、中介机构核查程序及核查意见 
（一）核查程序 
针对上述事项，保荐人、申报会计师核查依据、过程如下
1、对发行人财务、销售、运营部门负责人进行访谈，了解 B 端和 C 端具
体的销售及推广方式、推广服务的采购流程、采购价格及推广费的会计核算方

式。
2、获取发行人报告期内推广台账，检查主要推广服务商的采购合同、平台
充值消耗情况、上下刊报告及广告发布确认书，验证推广费的真实性、准确性
与完整性，并对推广费变动原因进行分析。
3、获取各推广渠道的获客数据，对推广费用、获客数量与收入等经营及财
务指标进行匹配性分析，并结合地域维度进行进一步分析。
4、计算获客成本，查阅同行业可比公司，分析推广渠道的分布情况、获客
成本的变动情况。
5、与人力、研发部门负责人进行访谈，了解公司人员组织架构、人员类别
划分依据、工时统计与归集方式以及研发、生产活动的开展情况。
6、查阅花名册、工资表及工时明细表，核查工资表人员划分是否正确，职
工薪酬是否按照实际工时进行合理分摊。
7、计算销售人员与研发人员的平均薪酬，了解发行人同行业可比公司的平
均薪酬水平，分析发行人低于同行业公司平均薪酬的原因及其合理性。
8、获取发行人报告期内研发费用加计扣除申报表及研发台账等资料，分析
发行人研发费用加计扣除金额与财务报表账面金额差异的原因，并判断其合理
性。检查纳税申报表、报告期初审计报告并重新测算广告宣传费相关可抵扣暂
时性差异金额，确保核算准确。
（二）核查意见 
基于上述核查，保荐人、申报会计师认为：
1、发行人推广服务真实、价格公允，推广获客存在地域性，获客成本变动
具有合理性，与同行业获客成本变动趋势一致。
2、报告期内发行人推广费核算完整，变动原因具备合理性，不存在其他方
为发行人承担费用成本的情形。
3、发行人明确区分研发活动与生产活动，人员属性划分清晰，符合行业惯
例，且报告期内保持一致。

4、发行人销售人员平均薪酬、研发人员平均薪酬与同行业可比公司存在一
定差异，具备合理原因。
5、发行人存在研发与生产共用资源的情形，人员工时准确统计，成本费用
准确归集与分配。
6、发行人研发费用加计扣除金额与报表研发费用金额主要系会计准则与税
务法规间的核算口径差异，差异具有合理性。广告宣传费相关可抵扣暂时性差
异系遵循税法相关规定所形成、核算准确。
