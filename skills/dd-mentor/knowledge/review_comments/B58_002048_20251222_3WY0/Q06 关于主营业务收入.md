（一）公司产品和服务是否包含付费后退货条款
根据《中华人民共和国消费者权益保护法（2013 年修正）》第二十五条，
数字化商品不适用七日无理由退货。公司在主要面向 C 端用户的产品用户协议
中约定，公司提供的会员类产品服务、数据报告查询下载等服务不适用无理由
退货，相关服务一经开通后不可退款，不违反相关法律法规。
经核查，发行人与可比公司产品用户协议针对退费的约定无重大差异，均
约定服务一经开通后不可退款，具体如下：

八、请保荐机构、申报会计师简要概括核查过程，并发表明确核查意见 
（一）核查程序 
1、与公司财务管理人员进行访谈，了解不同类型产品或服务的收入划分依
据，了解用户付费方式、付费时点、收入确认时点及确认依据，检查相关支持
性凭证；评估公司收入确认会计政策是否符合企业收入准则的相关规定；检查
上述收入是否存在自动化控制；
2、检查公司客户合同清单，获取既约定服务期间又计算实际消耗次数的产
品用户范围，复核该部分用户付费以及收入确认情况；
3、检查公司向用户提供“优惠”（含提供优惠券、免费会员体验、折扣、
延长会员有效期等）的记录，检查“优惠”对用户权益期间的影响，结合收入
准则复核“优惠”对收入确认的影响；
4、与公司销售部门负责人进行访谈，了解实际退货/退款的处理流程；抽
样检查了公司与 B 端和 C 端用户签订的主要销售合同及标准服务协议，重点关
注其中关于退货、退款、服务终止的条款；获取退款订单明细，复核退款对收
入确认的影响；
5、获取按 C 端用户和 B 端用户维度不同类型收入的明细表，获取 C 端用
户和 B 端用户数量、客户分布情况，查阅同行业上市公司公开披露数据，分析
公司用户数量、客户分布情况是否与同行业一致；
6、检查公司对不同类型收入的确认政策，区分属于时段法或时点法的摊销
方式，获取不同类型收入下的用户数量以及付费金额，并与收入进行匹配；
7、获取按地域分布维度的收入明细表，复核其分类准确性，查阅同行业上
市公司公开披露数据，分析公司是否与同行业一致；
8、利用 IT 审计专家工作，对收入确认相关的信息系统的关键控制进行测
试与评价，获取并复核信息系统专项审计报告，评价信息系统的有效性。
