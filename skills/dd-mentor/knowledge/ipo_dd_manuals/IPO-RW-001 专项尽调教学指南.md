# IPO专项尽调教学指南（改写版）

本指南将常见专项核查主题改写为可教学的风险分支。使用时应先引用通用尽调模块，再按项目事实选择本指南中的专项程序。

## 1. 销售收入

**触发事实**：收入增长较快、期末波动明显、合同或验收复杂、客户集中、第三方回款或回款偏慢。

**核心命题**：交易真实发生，金额准确，履约义务识别正确，收入确认在正确期间。

**证据链**：

`客户背景 → 合同和订单 → 履约或控制权转移 → 开票 → 回款 → 总账与报表`

**为什么要形成证据链**：任何单一凭证只能证明交易的一部分。合同证明约定，出库证明货物离开仓库，物流证明运输，签收或验收证明客户接收，发票证明结算或纳税，回款提供商业实质支持；它们不能相互替代。

**主要程序**：

- 按产品、模式、地区和客户拆分收入；
- 识别履约义务、可变对价和控制权转移条件；
- 将合同、出库、物流、签收验收、发票、回款和账务勾稽；
- 对期末前后交易执行截止测试；
- 对主要、新增、异常和长期未回款客户实施函证、访谈或替代程序；
- 检查退货、折扣、返利、质保和期后冲回；
- 比较销量、产量、存货、税务和现金流。

**异常分支**：

- 出库早于签收或验收 → 重新判断控制权转移时点并量化跨期；
- 回款来自非合同客户 → 核查第三方回款授权、原因、关联关系和资金闭环；
- 客户成立时间短或能力不匹配 → 穿透背景、终端销售和资金来源；
- 期后集中退货或冲回 → 扩大样本并评价虚假或提前确认。

## 2. 经销模式

**触发事实**：存在买断式或代理式经销、渠道层级多、终端信息弱、返利退货复杂。

**核心命题**：经销商具备商业实质，销售并非为压货，收入确认与权利义务相匹配。

**证据链**：

`经销商准入和能力 → 合同权利义务 → 公司发货 → 经销商库存和回款 → 终端销售或消耗`

**主要程序**：

- 分类经销模式并分析买断、退货、价格保护和返利条款；
- 比较经销和直销价格、毛利及信用政策；
- 核查主要经销商背景、资金能力、仓储和终端覆盖；
- 获取进销存、终端清单或替代性终端证据；
- 分析期末压货、跨区销售、库存积压和期后退货；
- 核对返利计算、审批、计提和结算。

**异常分支**：

- 经销商进货远高于终端消化 → 检查压货、退货权和收入冲回；
- 经销商与员工或股东重合 → 扩大关联关系和流水核查；
- 终端数据无法取得 → 组合使用物流、回款、访谈、库存和第三方数据。

## 3. 境外销售

**触发事实**：出口占比较高、海外主体或仓库较多、结算和贸易条款复杂。

**核心命题**：境外交易真实，出口、税务、制裁和收入确认处理适当。

**证据链**：

`境外客户 → 合同和贸易条款 → 报关和物流 → 签收或验收 → 收汇和退税 → 会计记录`

**主要程序**：

- 按国家、客户、产品、贸易方式和币种拆分；
- 将订单、报关、提单、物流、签收、收汇、退税和账务勾稽；
- 评价贸易术语对应的控制权转移时点；
- 检查海外仓、转口贸易、境外经销和第三方收付款；
- 评价制裁、出口管制、关税、外汇和税务风险；
- 分析汇率、信用期、退货和期后回款。

**异常分支**：

- 报关数量与收入不一致 → 排查样品、寄售、退运、时点或虚假出口；
- 收款国家或主体异常 → 穿透第三方付款和最终客户；
- 海外仓库存增长 → 盘点或函证并评价收入确认和跌价。

## 4. 资金流水

**触发事实**：IPO或高风险项目、客户供应商异常、第三方回款、个人卡、关联方或资金占用疑点。

**核心命题**：实际资金流与账面业务、关联方清单和公司治理一致。

**证据链**：

`完整账户 → 大额或异常流水 → 对手方身份 → 合同发票和账务 → 商业目的与审批 → 关联关系及资金占用判断`

**主要程序**：

- 确定核查主体、人员、账户和重要性口径；
- 验证账户完整性，关注销户、休眠和个人账户；
- 识别整额、频繁、同日进出、摘要异常和非交易对手方；
- 将流水与合同、发票、订单、工资、借款和分红等勾稽；
- 检查发行人、股东、管理层、员工和异常对手方之间的闭环；
- 对异常形成逐笔解释、证据和结论。

**异常分支**：

- 大额收款后迅速转出 → 追踪双向资金并识别循环；
- 对手方与账面客户供应商不同 → 核查第三方代付、授权和关联关系；
- 个人账户频繁收付 → 扩大个人卡、体外交易和收入成本完整性核查；
- 与股东管理层异常往来 → 评价资金占用、利益输送和披露。

## 5. 第三方回款

**核心命题**：付款安排具有真实商业原因，已获债务人授权，不用于掩盖虚假交易或关联关系。

**主要程序**：

- 统计金额、比例、付款方类型和变化；
- 核对合同、付款授权、付款方身份和基础交易；
- 检查付款方与客户、发行人及相关人员的关系；
- 追踪退款、转款或资金回流；
- 评价内部控制、整改和收入证据充分性。

**异常分支**：缺少授权、付款方无合理关系、资金快速回流或比例异常上升 → 扩大函证、访谈和流水穿透并重新评价收入真实性。

## 6. 个人卡

**核心命题**：公司不存在使用个人账户进行未入账收支、利益输送或规避内部控制的安排。

**主要程序**：

- 识别实际控制人、董监高、财务销售采购和出纳等高风险人员账户；
- 取得完整账户并与工资、报销、客户供应商和公司流水匹配；
- 分类个人卡收支并重建业务和账务；
- 检查余额归属、税务、关联交易和整改后的持续运行。

**异常分支**：个人账户收取客户款、支付供应商或存在大额不明往来 → 追踪最终资金、补记账务、评估税务和内控缺陷并扩大核查期间。

## 7. 销售业务抽查

**核心命题**：从业务发起到财务记录的正向测试和从账面到业务证据的反向测试均能闭环。

**程序设计**：

- 分层选择主要、随机、期末、新增、异常毛利和异常回款样本；
- 正向检查订单至入账，测试完整性；
- 反向检查账面至客户、履约和回款，测试真实性；
- 记录样本总体、选择逻辑、差异和扩样条件；
- 不以少量“典型样本”替代对异常总体的分析。

## 8. 采购业务抽查

**核心命题**：采购真实、完整、截止正确，成本和存货归集可靠。

**程序设计**：

- 勾稽申请、订单、到货、验收、入库、发票、付款和账务；
- 覆盖主要、异常价格、新增、关联、委外和期末样本；
- 正向测试采购完整性，反向测试真实性；
- 检查暂估、退货、折让和期后发票；
- 将采购量与生产、BOM、损耗和库存对应。

## 9. 现金交易

**核心命题**：现金交易具有行业合理性，记录完整，不被用于规避税务、内控或关联披露。

**主要程序**：

- 统计现金交易金额、频率、地区、对手方和业务原因；
- 检查收据、合同、物流、库存和资金存取；
- 识别拆分交易、白条、个人代收代付和账外资金；
- 比较同行业惯例并评价减少现金的整改。

**异常分支**：现金交易比例高、凭证不足或与个人账户联动 → 扩大资金和交易穿透，评价收入成本完整性及合规影响。

## 10. 在建工程

**核心命题**：工程真实存在，成本归集和进度可靠，转固及减值时点适当。

**主要程序**：

- 现场查看并与预算、合同、监理、付款和验收勾稽；
- 核查承包商能力、关联关系和异常资金流；
- 重算工程量、待摊支出、借款费用和转固时点；
- 识别长期停滞、超预算、闲置或重复建设。

## 11. 研发投入

**核心命题**：研发活动真实，人员和费用边界准确，成果和核心技术与投入相匹配。

**主要程序**：

- 建立项目、人员、工时、材料、设备、测试、成果和账务映射；
- 核查研发人员身份、履历、职责和薪酬分配；
- 区分研发、生产、售后、定制和日常维护；
- 检查委外研发、合作研发和知识产权归属；
- 评价资本化条件、政府补助和科创属性指标。

**异常分支**：工时集中填报、材料与产量不匹配、研发成果薄弱或人员兼岗严重 → 扩大原始记录和访谈，重算研发费用并评价板块定位。

## 12. 关联方及关联交易

**核心命题**：关联方识别完整，交易具有必要性、公允性和真实商业实质。

**主要程序**：

- 综合股权、任职、亲属、地址、联系方式、资金和历史关系识别；
- 对照工商、流水、客户供应商和员工数据；
- 比较价格、信用、毛利和结算条件；
- 检查代收代付、费用承担、担保和隐性安排；
- 评价交易减少或终止后的持续经营影响。

## 13. 资金占用

**核心命题**：控股股东、实际控制人及其他关联方未无偿或不当使用公司资金和资源。

**主要程序**：

- 检查其他应收款、预付款、借款、保证金和异常费用；
- 追踪与股东、管理层及其控制主体的资金；
- 识别无商业实质交易、代垫、循环付款和违规担保；
- 评价利息、审批、归还、整改和防范制度。

**异常分支**：期末归还期后再借、通过客户供应商中转或长期无息往来 → 穿透最终用途并评价持续性、内控和披露。

## 14. 软件企业内控系统

**核心命题**：系统中的用户、订单、履约、计费和收入数据完整可靠，系统权限能够防止未授权修改。

**主要程序**：

- 梳理业务、合同、计费、财务和支付系统接口；
- 测试用户访问、程序变更、日志、备份和接口控制；
- 将订单、活跃用户、使用量、开票、回款和收入勾稽；
- 检查手工订单、后台修改、测试账号和刷量；
- 评价订阅、许可、实施、维护和可变对价的收入政策。

## 15. 应收票据

**核心命题**：票据真实，权利完整，背书贴现和终止确认处理适当。

**主要程序**：

- 核对票据平台、原件、出票承兑方、期限和状态；
- 追踪票据对应销售、背书、贴现和到期兑付；
- 评价信用等级、追索权、受限和减值；
- 检查票据找零、无真实交易背景和关联方流转。

## 16. 应收票据期后事项

**核心命题**：报告期末票据在期后真实兑付或形成的损失、追索义务已被反映。

**主要程序**：

- 追踪到期兑付、拒付、展期、追索和重分类；
- 将期后银行流水与票据台账勾稽；
- 对未到期和异常票据更新信用风险；
- 评价期后事实是否要求调整减值或披露。

## 17. 商业贿赂

**核心命题**：销售和市场活动不存在通过佣金、礼品、招待、代理或第三方实施不当利益输送。

**主要程序**：

- 分析销售费用、咨询费、会议费、市场推广和代理佣金；
- 核查第三方能力、服务成果、定价、付款和最终受益人；
- 关注医疗、政府客户、招投标和高佣金地区；
- 检查举报、处罚、内部调查和整改；
- 将费用与员工及管理层流水、客户关系相互印证。

**异常分支**：服务证据不足、付款后提现或转至客户相关人员 → 扩大流水、电子数据和访谈，启动法律合规专项调查。

## 18. 对赌协议及特殊权利

**核心命题**：回购、估值调整、优先权和控制安排已完整识别，解除或恢复条件清晰。

**主要程序**：

- 收集投资协议、补充协议、承诺函和历史版本；
- 提取业绩、上市、回购、清算、反稀释和董事席位条款；
- 检查履行、豁免、解除和恢复安排；
- 评价控制权、负债确认、股份支付和信息披露影响。

## 19. 重大合同

**核心命题**：重大合同完整有效，权利义务、履行状态和交易影响被正确理解。

**主要程序**：

- 从合同台账、印章、付款、收入采购和法律函证验证完整性；
- 检查授权签署、期限、违约、赔偿、排他、最低承诺和控制权变更；
- 核对实际履行与合同条款；
- 识别补充协议、口头承诺和抽屉协议；
- 评价交易是否需要第三方同意。

## 20. 客户背景

**核心命题**：客户真实独立，具备与交易规模相符的经营能力和采购需求。

**主要程序**：

- 核查成立时间、股权、人员、地址、资质、经营和信用；
- 比较客户规模、终端用途、采购量和付款能力；
- 识别与发行人、股东、员工和其他客户供应商的关联；
- 对新增、异常、高毛利或低回款客户提高核查深度；
- 将背景结果与访谈、函证、物流和资金相互印证。

## 21. 客户供应商与发行人前员工关系

**核心命题**：相关交易具有独立商业实质，不是体外经营、利益输送或隐性关联安排。

**主要程序**：

- 核实离职时间、岗位、竞业、出资和实际控制；
- 比较交易形成时间与离职、设立和业务转移时间；
- 分析价格、毛利、信用、采购销售比例和经营能力；
- 穿透人员、地址、联系方式、设备、客户资源和资金往来；
- 评价关联方披露、独立性、商业必要性和替代性。

**异常分支**：离职后立即成为主要交易对手、经营资源来自发行人或资金存在回流 → 扩大背景、电子数据和流水核查，评价体外业务及控制权影响。

## 专项教学规则

每次引用本指南时，都应把程序改写成项目因果链：

`本项目事实 → 为什么形成风险 → 哪份证据证明哪一步 → 哪些证据必须相互勾稽 → 什么异常会改变判断 → 下一步进入哪条核查分支`

不得只复制程序名称或资料清单。
