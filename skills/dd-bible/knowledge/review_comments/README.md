# 监管问询及回复

本模块按交易所保存源文件目录；每条记录均将问询与对应回复保存在同一 Markdown 文件中，并包含 Project、Market、Wind 行业、问题属性及多标签。

- 上交所：142 份源文件，1382 条记录；见 [上交所监管问询及回复索引](上交所监管问询及回复索引.md)
- 深交所：186 份源文件，1299 条记录；见 [深交所监管问询及回复索引](深交所监管问询及回复索引.md)
- 合计：328 份源文件，2681 条记录
- 行业口径：按公司名称精确匹配 `industry.xlsx` Sheet2 的“Wind行业”列；Sheet2 未收录的 3 家公司采用用户指定分类。

所有源文件目录均直接位于本目录下，不保留 `batch` 等中间层级。
