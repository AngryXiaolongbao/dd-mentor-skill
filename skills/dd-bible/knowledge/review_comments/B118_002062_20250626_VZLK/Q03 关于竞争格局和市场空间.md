## 问询

根据申报材料：（1）工业自动化设备产品可分为控制层、驱动层、执行层与
传感层，通过系统集成形成整套控制系统产品，PLC 属于控制层的主要产品；发
行人以 PLC 业务为主，收入占比 2023 年达到 80%以上，同行业可比公司均非仅
从事 PLC 业务，多覆盖工业自动化领域多类产品或系统集成业务，产品覆盖自动
化设备的各个层级；（2）汇川技术、禾川技术、信捷电气等竞争对手仍以小型
PLC 为主营产品，主要 PLC 产品类型为中大型 PLC 的中控技术、和利时主要从事
系统集成业务；发行人中大型和小型 PLC 的毛利率分别约为 80%和 50%；（3）中
大型 PLC 主要应用领域为冶金、油气、市政公用等项目型行业和锂电设备、物流
仓储设备、光伏设备等 OEM 型行业；发行人产品下游应用领域主要为水利水电、
油气石化、轨道交通、船舶等项目型行业，OEM 型行业应用相对较少，国外西门
子等竞争对手下游应用领域覆盖项目型行业和 OEM 型行业；（4）发行人各期小型
PLC 产品收入分别为 848.56 万元、1,846.79 万元、2,292.89 万元、1,456.49 万
元；（5）2021 年至 2023 年，我国中大型 PLC 市场规模分别为 78.9 亿元、85.81
亿元、86.75 亿元，小型 PLC 市场规模分别为 79.58 亿元、84.05 亿元、73.69
亿元；发行人中大型 PLC 产品市场占有率为 0.91%、1.07%、1.37%。

一、发行人仅开展控制层产品业务的原因，结合不同品牌产品搭配使用效

（一）PLC 产品可以独立销售，且产品研发和推广需要较高的投入
PLC 作为工业自动化控制系统的核心设备，其功能独立性决定了其可以独立
存在并独立销售。PLC 承担着逻辑控制、数据处理、通信协调等关键任务，也主
导客户的使用体验。在完成各品牌工业自动化设备的物理安装后，系统的主要控
制逻辑编程工作在 PLC 平台实现，其他层级的工控设备主要执行 PLC 下发的控
制指令并反馈状态信号，PLC 在工业自动化系统的架构中有独立的功能，且主导
用户的使用体验，因此其可以独立销售而不是作为其他层级的工业自动化设备的
附属品。
PLC 的研发具有较高的技术难度和市场壁垒，一方面需要深入的理论研究与
长期的应用研发，另一方面由于国际品牌在中国市场的长期布局，已形成较强的
用户粘性和品牌壁垒，在打破市场门槛方面需要长期的努力。
发行人作为工业自动化控制领域的专业企业，自成立以来始终专注于 PLC
产品，尤其在中大型 PLC 领域持续深耕研发与技术创新。作为非上市企业，发
行人在资金实力、研发资源有限的条件下，聚焦于 PLC 这一工业自动控制层产
品领域，将有限的资源集中于 PLC 产品的技术突破和产业化应用，形成高效的
研发成果转化机制，这是发行人当前业务集中于工业自动化控制层产品的重要原
因。
（二）工业自动化设备的多元化经营并非市场的必然要求
在工业自动化领域，不同品牌的工控设备通过通用的标准化通信协议（如
PROFINET、EtherCAT、Modbus 等）实现互联，在技术层面并不存在兼容性障
碍。目前，同行业小型 PLC 厂商通常也会经营伺服、驱动、电机等产品，一方
面是同行业厂商的业务通常是从执行层、传感层向 PLC 控制层延伸，业务发展
渊源不同；另一方面是小型 PLC 产品从客户需求、成本控制等角度出发，与执
行层、传感层产品容易产生协同。中大型 PLC 产品的产业生态并不一样，系统

的设备复杂且专业化程度更高，多元化经营并非市场的必然要求。具体来说：
1、小型 PLC 市场具有成套采购、降成本的动力
小型PLC主要面向小型自动化设备，该领域的用户自主编程能力相对较弱，
系统集成经验不足，因此通常依赖设备供应商或技术增值经销商提供完整的系统
配置和调试服务，倾向于选择同品牌的一站式解决方案。为应对用户的使用习惯，
小型 PLC 企业通常会进行多产品经营，在提供 PLC 产品的基础上向客户一站式
销售伺服系统、驱动器、电机等其他层级产品。

服务，减少自身二次开发工作量，另一方面可以共同采购招标、降低采购成本。

习惯
中大型 PLC 用户主要为系统集成商，且在具体项目中，控制系统的设计、

此，选择设备时更注重产品的专业性能和在特定行业的应用案例，对品牌的关注
度较低，自主设计搭配方案，不存在使用单一品牌倾向。
此外，中大型 PLC 面临的下游整体工控系统需求，相较小型 PLC 面临的场
景，所涉设备种类要多很多，且专业化程度高，除 PLC 产品外还包括阀门、流
量计、压力变送器等等，而非简单的伺服、电机。不同类型设备通常来自不同领
域的专业供应商，单一品牌难以通过多产品经营满足用户的所有需求。
综上，覆盖控制层、驱动层、执行层产品的多元化经营模式并非中大型 PLC
市场的普遍需求。发行人专注于中大型 PLC 产品，能够更深入地满足客户对核
心控制设备的高性能要求，而无需分散资源至其他层级产品，不影响发行人的市

在工业自动化领域，PLC 根据客户的使用方式和特点，下游市场整体可分为
项目型（Project-Based）和 OEM 型（Original Equipment Manufacturer-Based）两
大类。其中，项目型市场通常指的是针对特定客户或项目的定制化解决方案。如
石油化工厂、发电站等，需要根据具体需求进行设计和实施。这类项目通常规模
较大，涉及多个子系统和复杂的集成。OEM 型市场则是指原始设备制造商将 PLC
集成到自己生产的设备中，作为标准化的组件。如机床制造商、包装机械制造商
等，他们会在自己的设备中嵌入 PLC，以实现设备的自动化运行。
但是，具体到某一应用领域，可能同时涉及项目型和 OEM 型。以汽车行业

车生产线通常属于项目型市场，需要定制化的自动化解决方案，包括焊接机器人、
装配线控制等，需要通过中大型 PLC 进行复杂度控制调度。而汽车零部件制造
设备，如发动机缸体加工中心、轮胎成型机等，则更多属于 OEM 型市场，这些
设备由专门的设备制造商生产，并批量销售给汽车厂商。目前下游应用市场类型
