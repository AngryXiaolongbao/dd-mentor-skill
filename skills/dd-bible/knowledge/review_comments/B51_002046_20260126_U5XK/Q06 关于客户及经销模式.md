1、重点行业市场采购政策要求及业务流程情况
（1）重点行业市场采购政策要求
1）明确采购标准：需采购通过相关测评的 CPU、操作系统和数据库等软、
硬件；
2）区分技术架构划分采购包：重点行业产业技术路线主要为 X86（如海光
/兆芯）、ARM（如鲲鹏/飞腾）、自主指令集（如龙芯/申威）三大架构，要求
所有重点行业项目按照架构划分为独立采购单元，并确保每包内至少有三家厂
商（主要终端品牌商）公平竞争；
3）建立采购负面清单：严禁地方政府在招标中设置地域性门槛，明确采购
负面清单，禁止设置地域壁垒和指定特定品牌芯片，违者将面临采购计划冻结；

4）建立价格监测机制：要求厂商报价偏离行业均价超 10%必须说明理由，
倒逼企业合理定价。
（2）采购业务流程
重点行业市场内，终端客户对于台式计算机、便携式计算机、服务器等整
机的采购存在多种方式，包括“框架采购”、“招投标采购“、“邀标采购”
等，相关业务流程具体如下：
1）“框架采购”
框架采购是重点行业市场采购中（尤其是各省重点行业市场采购、央采）
的常见模式，核心是“预先搭建入围框架，后续按需选用”。
①标包预设：由央采中心或省采购中心与各终端品牌商沟通，根据不同
CPU 架构、技术路线，设置对应产品的标包。
②厂商投标与入围：终端品牌商针对不同 CPU 技术路线的标包投标，经过
10%-20% 的淘汰率筛选后，中标者进入 “入围框架”。
③用户采购：后续各用户单位可在入围框架内，自主选择符合需求的产品，
直接下单采购。
2）招投标采购（公开招投标）
公开招投标是重点行业市场另一种常见方式，核心是 “公开标书、全市场
参与，通过参数约束锁定需求”。
①标书公开：采购需求（含重点行业市场相关要求）以标书形式公开发布，
所有符合资质的企业均可参与投标。
②参数约束：标书会明确 CPU 架构、参数要求，甚至直接锁定某一款
CPU 型号；终端品牌商需根据标书要求，用对应产品应标。
③前期铺垫：最终用户通常会提前与 终端品牌商沟通、开展测试测评，再
通过标书设置 “参数限制、案例加分、价格评分方法” 等规则，确保中标产品
符合自身使用需求。
3）邀标采购（含邀标集中采购、涉密邀标采购）

邀标是“邀请特定厂商参与”的采购方式，核心是“定向邀请、前期深度
调研”。
①定向邀请：仅邀请部分整机厂商参与重点行业市场项目投标，不向全市
场公开。
②前期调研：需提前对重点行业市场 CPU 技术路线、终端品牌商资质等进
行全方位沟通和评测，确保邀请对象符合项目需求。

在接收客户的采购订单后完成产品交付。
经销模式下，经销商结合市场情况及终端客户需求向公司下达订单，后续
的出货及财务结算由公司与经销商双方完成。经销模式一方面有利于公司开拓
市场和客户维护，扩大市场份额，另一方面为终端客户提供外汇结算、进出口
手续办理、多种整机原材料集中采购等便利。
报告期内，发行人不存在下游客户指定经销商交易的情况。
4、国产终端品牌商采购计划中是否指定 CPU 架构、型号或性能以及对发
行人的具体影响
随着国家对信息安全和自主可控能力的重视，为了规范重点行业市场的市
场化、标准化长远发展，财政部、工信部等部委相继出台了一系列政策文件，
明确要求政府采购的重点行业市场产品必须通过相关测评。例如，财政部、工
业和信息化部于 2023 年 12 月发布 7 项基础软硬件政府采购需求标准，中央政
府采购网于 2024 年 3 月发布《关于更新中央国家机关台式计算机、便携式计算
机批量集中采购配置标准的通知》等，明确：乡镇以上党政机关，以及乡镇以
上党委和政府直属事业单位及部门所属为机关提供支持保障的事业单位在采购
台式计算机、便携式计算机时，应当将 CPU、操作系统符合相关测评要求纳入
采购需求。
基于上述重点行业市场要求，国产终端品牌商在采购 CPU 芯片时，一般均
以通过相关测评作为采购标准要求。截至目前，通过相关测评的 CPU 企业仅有
兆芯集成、海光信息、华为海思、龙芯中科、飞腾信息、电科申泰，其中 x86
架构的仅有兆芯集成与海光信息。基于 CPU 产品特殊性以及同一架构下供应商
数量有限，终端品牌商在采购 CPU 芯片时一般明确 CPU 架构、对应厂商及产
品型号，并采取单一来源采购、定向协商等方式开展具体采购。
重点行业市场中关于所有重点行业项目按照架构划分为独立采购单元，并
确保每包内至少有三家厂商公平竞争的要求，仅指最终用户在向国产品牌商采
购台式计算机、便携式计算机、服务器等整机时，需要确保同一架构下至少三
家品牌厂商进行公平竞争和选择，对于终端品牌商等客户向发行人采购 CPU 芯
片的流程与要求并无重要影响。

（一）核查程序

速增长的原因及合理性”。相关产品除 6000G 因产品测评原因导致部分项目执
行受阻外，KX-6000 和 KX-7000 均具备较高的期后消化率，与经销商的 3-6 个
月销售周期匹配。
综上，发行人不存在提前大额备货的情况，主要订单具备合理性。
五、中介机构核查意见
（一）核查程序
保荐机构及申报会计师进行了如下核查：
1、访谈公司销售主要负责人，了解公司与经销商的公司 N、上海众新、东
海信息的交易情况，通过经销模式间接采购的原因，经销商长库龄产品的具体
情况、是否存在销售退回风险等；
2、访谈公司 N、上海众新、东海信息的相关负责人，了解其通过经销模
式间接采购的原因，采购情况、消化使用情况等；取得了公司 N、上海众新、
东海信息的进销存及领用记录，并与发行人的销售记录、经销商进销存等进行
核对；
3、访谈发行人主要经销商，了解经销商的采购销售情况、业务模式、终端
客户情况，发行人产品消化、退换货情况等；
4、获取了发行人主要买断式经销商的进销存，统计主要终端客户的采购情
况、发行人产品的销货情况、库存消化情况，库龄情况等；获取了发行人非买
断式经销模式下经销商销售清单、销售出库单、终端客户签收单据等；针对经
销商销售周期、长库龄产品的具体情况等进行分析；
5、查阅公司的会计记录，获取公司与经销商的合同、订单、出货单、物流
单、签收单据、回款记录、销售发票、记账凭证等文件；统计发行人交付情况，
分析订单签署时间、付款时间、收入确认时间的匹配关系并与经销商进销存情
况进行匹配；
6、获取发行人报告期内客户收入明细、非买断式 KH-40000 产品终端销售
清单，了解 KH-40000 产品上市后的推广和销售进展，并分析产品关联方终端

销售占比情况；
7、获取联和投资与公司 N 间的借款协议、联和投资关于借款事项相关的
董事会决议文件，以及借款相关的会计凭证和银行回单，核查 7000 万借款与发
行人的关系；
8、取得发行人 2020 年资金流水，分析公司、联和投资和公司 N 的资金往
来是否存在异常。
（二）核查结论
经核查，保荐机构及申报会计师认为：
1、关联方公司 N、上海众新、东海信息通过经销模式间接采购的交易具备
合理性，不存在关联交易非关联化情形；
2、报告期各期，KH-40000 并非主要由关联方采购，相关关联方采购 KH￾40000 的原因具备合理性；联和投资向公司 N 提供 7,000 万元委托贷款的资金来
源于联和投资的自有资金，主要用于公司 N 的资金周转，与发行人无任何关联；
3、发行人经销商库存中长库龄产品主要为 KX-6000G 和 ZX-200，后续已
逐步开启销售，其整体金额影响较小；经销商预计后续可以逐步完成相关库存
的消化，如非合同约定的质量问题，不存在销售退回风险；
4、发行人经销商不存在提前大额备货的情形。
