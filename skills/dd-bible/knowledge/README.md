# DD Bible knowledge base

This packaged knowledge base contains two different source layers:

1. **Rewritten diligence guidance** — original manuals are not included. Their themes have been transformed into teaching-oriented knowledge organized around objectives, risks, evidence, procedures, red flags, and follow-up branches.
2. **Regulatory inquiry and response records** — public exchange inquiry-and-response records are retained as searchable Markdown entries with project, market, industry, topic, and source metadata.

## Modules

| Module | Path | Treatment |
| --- | --- | --- |
| General diligence framework | `general_dd_manuals/` | Rewritten and reorganized |
| IPO topic guides | `ipo_dd_manuals/` | Rewritten and reorganized |
| Regulatory inquiries and replies | `review_comments/` | Directly retained public records |

## Use boundary

- The rewritten guides are educational planning aids, not quotations from or substitutes for the original manuals.
- Regulatory records are examples of review focus, not universal rules.
- Check the underlying public filing before relying on a regulatory record externally.
- Do not add client documents, confidential work papers, personal information, credentials, or local logs to this directory.
